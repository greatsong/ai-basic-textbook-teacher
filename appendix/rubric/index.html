A1. 활성화함수의 역할 + ReLU vs Sigmoid (10점)

섹션 제목: “A1. 활성화함수의 역할 + ReLU vs Sigmoid (10점)”
채점 요소배점상 기준
비선형성 도입 역할3점”공간을 구부려 비선형 패턴을 표현”이라는 핵심을 정확히 서술
ReLU 특성3점max(0,x), 기울기 항상 1, 기울기 소실 없음
Sigmoid 특성2점0~1 압축, S자 곡선, 기울기 소실 문제
비교/예시2점구체적 차이점 비교 또는 XOR 예시 활용

감점 사유

  • “뉴런을 켜고 끈다”만 쓰면 → 중 이하
  • ReLU와 Sigmoid의 차이를 안 쓰면 → 하
  • 기울기 소실을 전혀 언급하지 않으면 → 중

최적화 방법2점경사하강법으로 최적화한다는 연결
한계 인식2점손실 최소화 ≠ 정답을 아는 것

A3. 경사하강법의 원리 (10점)

섹션 제목: “A3. 경사하강법의 원리 (10점)”
채점 요소배점상 기준
기울기 개념3점”손실이 줄어드는 방향을 알려주는 나침반”
학습률3점이동 크기 + 너무 크거나 작을 때의 문제

방법 1: 상대평가 (등급제)

섹션 제목: “방법 1: 상대평가 (등급제)”
등급비율서술형 점수 기준참여도 기준
A상위 30%85점 이상평균 4점 이상
B다음 40%60~84점평균 3점 이상
C나머지 30%59점 이하평균 2점 이하

방법 2: 절대평가 (성취수준)

섹션 제목: “방법 2: 절대평가 (성취수준)”
수준서술형참여도설명
성취70점 이상평균 3점 이상핵심 개념을 이해하고 활용할 수 있음
노력 필요40~69점평균 2점 이상일부 개념을 이해하나 적용에 어려움
미도달39점 이하평균 2점 미만핵심 개념의 이해가 부족

5. 채점 시 자주 발생하는 판단 상황

섹션 제목: “5. 채점 시 자주 발생하는 판단 상황”

상황 1: 개념을 정확히 썼지만 4개 중 3개만 포함 (C1)

섹션 제목: “상황 1: 개념을 정확히 썼지만 4개 중 3개만 포함 (C1)”

→ 누락 항목 0점 + 나머지 항목의 질에 따라 15점 내외. 전체적으로 중~중상.

상황 2: 4개 개념을 모두 썼지만 나열식이고 인과관계가 없는 경우

섹션 제목: “상황 2: 4개 개념을 모두 썼지만 나열식이고 인과관계가 없는 경우”

→ 각 항목 3점씩 = 12점. 중.

상황 3: “환각은 확률적 예측 때문”이라고만 쓰고 나머지 없음

섹션 제목: “상황 3: “환각은 확률적 예측 때문”이라고만 쓰고 나머지 없음”

→ 확률적 예측 3점 + 나머지 0점 = 3점. 하~미달.

상황 4: 교과서 예시 답안을 거의 그대로 베낀 경우

섹션 제목: “상황 4: 교과서 예시 답안을 거의 그대로 베낀 경우”

→ 내용이 정확하면 점수는 인정. 자기 표현이 아님을 기록. 향후 변별 참고.

상황 5: 교과서에 없는 자기만의 비유나 예시를 사용한 경우

섹션 제목: “상황 5: 교과서에 없는 자기만의 비유나 예시를 사용한 경우”

→ 정확하면 오히려 가산. 창의적 이해의 증거로 평가.

상황 6: 한글 맞춤법이 틀리거나 문장이 어색한 경우

섹션 제목: “상황 6: 한글 맞춤법이 틀리거나 문장이 어색한 경우”

→ 내용의 정확성이 핵심이므로, 표현의 어색함으로 감점하지 않음. 핵심 개념이 정확한지만 판단.
