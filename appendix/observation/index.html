학생 관찰 기록

관찰 기록의 목적

섹션 제목: “관찰 기록의 목적”

과정 중심 평가에서 교사의 관찰 기록은 학생의 사고 과정, 협업 능력, 태도 변화를 포착하는 핵심 도구입니다. 서술형 평가가 “최종 이해도”를 측정한다면, 관찰 기록은 “이해에 이르는 과정”을 기록합니다.

관찰 기록 원칙

  1. 행동 중심 기록: “잘했다/못했다” 대신 “~라고 말했다”, “~를 시도했다” 형태로 기록
  2. 실시간 기록: 수업 후 기억에 의존하지 말고, 순회 중 즉시 메모
  3. 선택적 기록: 모든 학생을 매 차시 기록할 필요 없음. 차시당 5~8명 집중 관찰
  4. 긍정 편향 주의: 문제 행동뿐 아니라 좋은 발언, 창의적 시도도 기록

기본 양식 (인쇄용)

섹션 제목: “기본 양식 (인쇄용)”

아래 양식을 차시마다 인쇄하여 수업 중 클립보드에 끼워 사용하세요.

차시별 핵심 관찰 포인트

섹션 제목: “차시별 핵심 관찰 포인트”

각 차시에서 특히 주의 깊게 관찰해야 할 행동과 발언을 정리했습니다.

1차시: 기계가 생각할 수 있는가?

섹션 제목: “1차시: 기계가 생각할 수 있는가?”
관찰 시점관찰 대상주목할 발언/행동
도입 (0-3분)질문에 대한 초기 반응”당연히 못 하죠” vs “ChatGPT는 생각하는 것 같은데요?” — 사전 인식 파악
실험 중 (8-35분)질문 전략감정/경험을 묻는 질문 vs 사실 확인 질문 — 직관적 판별 전략
정답 공개 후 (35-38분)놀라움의 정도”사람인 줄 알았는데 AI였어요!” — 이 반응의 강도가 이후 토의의 깊이 예측
중국어 방 (38-43분)철학적 반응”행동이 같으면 같은 거 아닌가요?” — 튜링 관점의 학생 표시
성찰 기록 (48-50분)답변의 구체성한 줄 답변 vs 여러 줄 답변 — 10차시 before/after 비교의 기초

핵심 관찰 질문: “이 학생은 ‘행동 vs 이해’의 구분을 인식하고 있는가?“

2차시: 기계가 스스로 학습할 수 있는가?

섹션 제목: “2차시: 기계가 스스로 학습할 수 있는가?”
관찰 시점관찰 대상주목할 발언/행동
AND/OR 실습 (3-18분)시뮬레이터 조작 능력슬라이더를 체계적으로 움직이는가, 무작위로 움직이는가
XOR 도전 (33-45분)좌절 반응”이거 왜 안 되죠?” — 좌절을 표현하는 학생은 3차시 동기 부여가 강함
XOR 도전 (33-45분)가설 수립”대각선으로 있어서 안 되나?” — 선형 분리 불가능성의 직관
직선 2개 (40-45분)해결 반응”아! 2개면 되네!” — 이 발견의 기쁨이 다층 신경망 이해의 기초

핵심 관찰 질문: “이 학생은 XOR에서 충분히 좌절했는가?” (좌절이 클수록 3차시 임팩트가 큼)

3차시: AI의 겨울을 이겨낸 알고리즘의 발견

섹션 제목: “3차시: AI의 겨울을 이겨낸 알고리즘의 발견”
관찰 시점관찰 대상주목할 발언/행동
OFF 상태 실패 (3-8분)혼란 표현”2차시에서 직선 2개 쓰면 된다고 했는데 왜 안 돼요?”
ON 전환 후 (8-15분)놀라움”와, 스위치 하나 켰을 뿐인데!” — 이 반응의 강도 기록
4종 비교 (25-33분)차이 인식Sigmoid → ReLU 전환 시 학습 속도 차이를 관찰했는가
파라미터 카운팅 (33-45분)규모 감각”17개인데 GPT-4는 수천억?” — 규모 차이에 대한 감탄

핵심 관찰 질문: “이 학생은 활성화함수 ON/OFF의 차이를 직접 체험했는가?“

4차시: 잘 학습됐다는 것을 어떻게 알 수 있을까?

섹션 제목: “4차시: 잘 학습됐다는 것을 어떻게 알 수 있을까?”
관찰 시점관찰 대상주목할 발언/행동
직선 피팅 대결 (3-18분)경쟁 참여도적극적으로 슬라이더 조절, 손실값에 관심
라운드 3 이상치 (15-18분)이상치 반응”이 점 하나 때문에 손실이 확 올라갔어요!” — 제곱 효과 체감
MSE 손계산 (18-33분)계산 능력계산 과정의 정확성, 계산기 사용 여부
등고선 탐험 (33-45분)직관 형성”가장 파란 곳으로 가면 되는 거 아니에요?” — 최적화 직관

핵심 관찰 질문: “이 학생은 ‘학습 = 손실 줄이기’라는 정의를 자기 말로 표현할 수 있는가?“

5차시: 오차 줄이는 방향으로 나아가는 방법

섹션 제목: “5차시: 오차 줄이는 방향으로 나아가는 방법”
관찰 시점관찰 대상주목할 발언/행동
1차 직감 도전 (3-20분)결과 유형발산/정체/성공/로컬 미니마 — 어떤 경험을 했는지 기록
이론 연결 (20-33분)경험-이론 매칭”아까 공이 날아간 게 학습률이 너무 커서였군요!”
팀 전략 토의 (33-35분)토의 참여구체적 숫자로 전략을 세우는가 vs 감으로 하는가
2~3차 도전 (35-48분)전략의 개선1차 vs 2~3차 결과가 개선되었는가

핵심 관찰 질문: “이론을 배운 후 전략이 구체적으로 바뀌었는가?” (지식의 실용적 가치 체감)

6차시: 오차를 줄이는 과정을 자동화하려면

섹션 제목: “6차시: 오차를 줄이는 과정을 자동화하려면”
관찰 시점관찰 대상주목할 발언/행동
순전파 계산 (3-20분)계산 수행가중합 → Sigmoid → 오차까지 완수했는가
역전파 예측 (20분)직관”출력에 가까운 가중치가 더 많이 바뀌지 않을까요?”
학습 반복 (35-47분)감탄”100번 누르니까 손실이 거의 0이에요!” — 기계 학습 체감
전체 통합 (47분)연결 능력4~6차시를 하나의 흐름으로 연결하는 발언

핵심 관찰 질문: “순전파→오차→역전파→업데이트 4단계를 순서대로 말할 수 있는가?“

7차시: 단어를 숫자로 표현하면 계산할 수 있다

섹션 제목: “7차시: 단어를 숫자로 표현하면 계산할 수 있다”
관찰 시점관찰 대상주목할 발언/행동
토큰화 대결 (3-15분)호기심”한국어가 영어보다 토큰이 더 많아요!” — 언어 형평성 인식
벡터 연산 (15-28분)이해도”왕 - 남자 + 여자 = 여왕” 결과에 대한 놀라움
임베딩 갤럭시 (28-47분)탐구 정도다양한 단어를 실험하는가, 패턴을 찾으려 하는가
의미 지도 발견 (28-47분)통찰”과일끼리 모여있고, 동물끼리 모여있어요!”

핵심 관찰 질문: “토큰 번호와 임베딩의 차이를 이해하는가?“

8차시: ChatGPT의 작동 원리

섹션 제목: “8차시: ChatGPT의 작동 원리”
관찰 시점관찰 대상주목할 발언/행동
다음 단어 예측 (3-18분)참여도다양한 문장으로 실험하는가
Temperature 실험 (10-18분)직관”0.1이면 항상 같은 답, 2.0이면 엉뚱한 답!”
환각 체험 (35-47분)충격”없는 논문을 자신있게 요약해줬어요!”
전체 통합 (35-47분)연결 능력1~8차시의 개념을 파이프라인으로 연결

핵심 관찰 질문: “환각이 ‘멍청해서’가 아니라 ‘구조적 필연’임을 이해하는가?“

9차시: 퍼셉트론에서 ChatGPT까지

섹션 제목: “9차시: 퍼셉트론에서 ChatGPT까지”
관찰 시점관찰 대상주목할 발언/행동
팀 탐구 (3-25분)역할 수행기록/발표/탐구 역할 분담과 수행 정도
인과관계 파악 (3-25분)추론 능력”퍼셉트론의 한계 때문에 AI 겨울이 왔고…”
퀴즈 (25-40분)지식 범위자기 팀 카드 외의 문제도 맞히는가
”가장 중요한 논문” 발표 (40-50분)판단력선택의 근거가 논리적인가

핵심 관찰 질문: “7편의 논문이 인과적 사슬로 이어진다는 것을 이해하는가?“

10차시: 같은 질문, 다른 깊이

섹션 제목: “10차시: 같은 질문, 다른 깊이”
관찰 시점관찰 대상주목할 발언/행동
한계 실험 (3-25분)분석 태도”틀렸다” vs “왜 틀렸는지” — 분석적 접근 여부
모둠 토의 (25-40분)개념 활용구체적 수업 개념으로 설명하는가
before/after (40-50분)성장 인식1차시 답변과의 차이를 스스로 인식하는가
마무리태도 변화”AI가 멍청해서” → “구조적으로 불가피하기 때문에” 전환

핵심 관찰 질문: “이 학생의 답의 ‘깊이’는 1차시 대비 얼마나 바뀌었는가?”

효율적 기록 방법

섹션 제목: “효율적 기록 방법”
  1. 순회 동선 계획: 매 차시 집중 관찰할 학생 5~8명을 미리 정하세요. 10차시에 걸쳐 모든 학생을 최소 2회 이상 관찰합니다.
  2. 기호 사용: 시간이 부족할 때는 기호를 활용하세요.
    • ★ = 탁월한 발언/행동
    • ? = 오개념 또는 혼란 징후
    • ↑ = 이전 차시 대비 성장
    • → = 추가 지원 필요
  3. 사진 촬영: 학생 워크시트, 모둠 토의 결과물을 사진으로 기록해두면 평가 시 근거가 됩니다.

수업 중 정확한 개념 발언이 있었으나, 서술형에서 표현이 부족구두 능력을 감안하여 서면 점수의 하한선을 올려줄 수 있음
서술형은 잘 썼으나, 수업 중 참여가 저조했던 학생모범 답안을 베낀 것일 수 있으므로, 다음 기회에 구두 확인
매 차시 성장이 관찰되는 학생과정 중심 평가에서 높은 점수 부여 근거
특정 개념에서 반복적으로 오개념을 보이는 학생개별 피드백 시 해당 개념을 집중 보충
