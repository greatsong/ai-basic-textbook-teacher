## 1. 과정중심평가 개요

과정중심평가란 교육과정 성취기준에 기반하여, 교수·학습 과정에서 학생의 변화와 성장에 대한 자료를 다각도로 수집하고 적절한 피드백을 제공하는 평가이다. AI 기초 수업은 매 차시 시뮬레이터 실습, 사고실험, 모둠 토의 등 **과정 자체가 학습의 핵심**이므로 과정중심평가에 특히 적합하다. 최종 서술형 점수만으로는 포착할 수 없는 사고의 변화(1차시 "AI는 멍청해서" → 10차시 "구조적 필연")를 기록하고, 즉각적 피드백으로 학습을 촉진한다.

## 2. 평가 프레임워크

```
총점 100점
├── 과정평가 40점 (수업 중 수집)
│   ├── 교사 관찰 평가 ····· 20점 (차시별 관찰 체크리스트)
│   ├── 포트폴리오 ········· 10점 (차시별 산출물 모음)
│   └── 동료 평가 ·········· 10점 (모둠 활동 상호 평가)
│
└── 결과평가 60점 (수업 후 수집)
    ├── 형성평가 ············ 10점 (1-8차시 퀴즈/활동 요약)
    ├── 서술형 평가 ········· 40점 (A·B·C유형 7문항, 100점 만점 → 40점 환산)
    └── Before/After 성찰 ·· 10점 (1차시 vs 9-10차시 비교)
```

## 4. 과정평가 도구 (40점)

### 4-1. 교사 관찰 평가 (20점)

10차시 전체 관찰 점수의 평균을 20점 만점으로 환산한다. 차시당 5~8명을 집중 관찰하여 10차시 동안 모든 학생을 최소 3회 이상 기록한다.

#### 5단계 관찰 척도

| 점수 | 수준 | 판단 기준 |
|------|------|----------|
| 5 | 탁월 | 적극 참여 + 창의적 기여 (새로운 질문 제기, 동료 학습 도움, 독창적 전략) |
| 4 | 우수 | 적극 참여 (활동 완수, 토의 의견 제시, 질문에 대답 시도) |
| 3 | 보통 | 기본 참여 (활동 수행하나 발언 적음) |
| 2 | 미흡 | 소극적 참여 (집중도 낮음, 토의 불참) |
| 1 | 부족 | 참여 거부 또는 방해 |

#### 차시별 관찰 체크리스트 (인쇄용 통합표)

아래 표를 인쇄하여 학생 1인당 1장씩 사용한다. 해당 차시에 관찰 대상이 아닌 경우 빈칸으로 둔다.

```
┌──────────────────────────────────────────────────────────────────┐
│ 학생명: ______________  학번: __________  반: ____               │
├────┬────────────────────────────────┬──────┬────────────────────┤
│차시│ 핵심 관찰 항목                  │ 척도 │ 메모               │
│    │                                │(1-5) │                    │
├────┼────────────────────────────────┼──────┼────────────────────┤
│ 1  │ 튜링 테스트 질문 전략 다양성    │      │                    │
├────┼────────────────────────────────┼──────┼────────────────────┤
│ 2  │ XOR 좌절 경험 및 가설 제시      │      │                    │
├────┼────────────────────────────────┼──────┼────────────────────┤
│ 3  │ 활성화함수 ON/OFF 반응 깊이     │      │                    │
├────┼────────────────────────────────┼──────┼────────────────────┤
│ 4  │ 직선 피팅 전략성 + 이상치 관찰  │      │                    │
├────┼────────────────────────────────┼──────┼────────────────────┤
│ 5  │ 레이싱 전략 수립 및 이론 연결   │      │                    │
├────┼────────────────────────────────┼──────┼────────────────────┤
│ 6  │ 순전파 손계산 완수 여부         │      │                    │
├────┼────────────────────────────────┼──────┼────────────────────┤
│ 7  │ 임베딩 갤럭시 탐험 패턴 발견    │      │                    │
├────┼────────────────────────────────┼──────┼────────────────────┤
│ 8  │ Temperature 실험 + 환각 원인 고찰│      │                    │
├────┼────────────────────────────────┼──────┼────────────────────┤
│ 9  │ 팀별 논문 탐구 + 인과관계 파악  │      │                    │
├────┼────────────────────────────────┼──────┼────────────────────┤
│ 10 │ 한계 실험 분석 + 구조적 설명    │      │                    │
├────┴────────────────────────────────┴──────┴────────────────────┤
│ 관찰 횟수 합계: ____회   평균 점수: ____점                        │
│ 종합 메모:                                                       │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
```

**기록 원칙:**
- 행동 중심 기록 ("잘했다" 대신 "~라고 말했다", "~를 시도했다")
- 순회 중 즉시 메모 (수업 후 기억에 의존하지 않음)
- 기호 활용: ★ 탁월한 발언, ? 오개념 징후, ↑ 성장, → 추가 지원 필요

#### 관찰 점수 → 20점 환산

관찰된 차시들의 평균 점수를 다음과 같이 환산한다.

| 평균 점수 | 환산 점수 |
|----------|----------|
| 4.5 이상 | 20 |
| 4.0~4.4 | 18 |
| 3.5~3.9 | 16 |
| 3.0~3.4 | 14 |
| 2.5~2.9 | 12 |
| 2.0~2.4 | 10 |
| 2.0 미만 | 8 이하 (비례) |

### 4-2. 학생 자기 평가

자기 평가는 성적에 직접 반영하지 않으나, 메타인지 촉진과 교사 피드백 자료로 활용한다.

#### 차시별 자기 점검 체크리스트 (구글 설문 또는 인쇄)

각 차시 종료 2분 전, 학생이 스스로 체크한다.

| 항목 | 5 | 4 | 3 | 2 | 1 |
|------|---|---|---|---|---|
| 오늘 활동에 적극적으로 참여했다 | | | | | |
| 오늘 배운 핵심 개념을 한 문장으로 말할 수 있다 | | | | | |
| 궁금한 점이 생겼거나 새롭게 알게 된 것이 있다 | | | | | |

**메타인지 기록 (한 줄):**
> "오늘 수업에서 가장 '아하!'했던 순간은? ________________"

### 4-3. 동료 평가 (10점)

9차시, 10차시 모둠 활동 종료 후 실시한다. 자신을 제외한 모둠원을 각각 평가한다.

#### 동료 평가 양식 (5단계 척도)

| 평가 항목 | 5 | 4 | 3 | 2 | 1 |
|----------|---|---|---|---|---|
| **역할 수행**: 맡은 역할을 책임감 있게 수행했다 | | | | | |
| **의견 제시**: 구체적 근거를 들어 의견을 말했다 | | | | | |
| **경청 및 보완**: 다른 사람의 의견을 듣고 보완했다 | | | | | |
| **개념 활용**: 수업에서 배운 개념을 토의에 활용했다 | | | | | |

**운영 규칙:**
- 익명 처리 (교사만 확인)
- 극단 점수(전원 5점 또는 전원 1점) 시 교사가 교차 확인
- 동료 평가 점수 = 받은 점수의 평균 (20점 만점) → 10점 환산

| 동료 평가 평균 | 환산 점수 |
|--------------|----------|
| 4.5 이상 | 10 |
| 4.0~4.4 | 9 |
| 3.5~3.9 | 8 |
| 3.0~3.4 | 7 |
| 2.5~2.9 | 6 |
| 2.0~2.4 | 5 |
| 2.0 미만 | 4 이하 (비례) |

### 4-4. 포트폴리오 (10점)

#### 차시별 수집 산출물

| 차시 | 산출물 | 형태 |
|------|--------|------|
| 1 | 구글 설문 성찰 기록 (Before) | 디지털 |

| 5 | 레이싱 전략 기록 (1차 vs 2~3차 비교) | 수기/디지털 |
| 6 | 순전파 계산 워크시트 | 수기 |
| 7 | 토큰화 실험 + 임베딩 탐험 기록 | 디지털 |

| 수준 | 점수 | 기준 |
|------|------|------|

| 중 | 6~8 | 5~7개 산출물 제출, 기록이 있으나 깊이가 부족한 항목 존재 |
| 하 | 3~5 | 3~4개 산출물 제출, 또는 형식적 기록 |

## 5. 결과평가 도구 (60점)

### 5-1. 형성평가 (10점)

1~8차시 수업 중 실시하는 간단한 확인 활동을 종합한다. 별도 시험이 아니라 수업 활동의 완수 여부와 정확성을 기준으로 평가한다.

| 차시 | 형성평가 내용 | 확인 방법 |
|------|-------------|----------|
| 2 | AND/OR 분류 성공 + XOR 실패 경험 | 시뮬레이터 기록 |
| 3 | 활성화함수 ON/OFF 실험 완수 | 시뮬레이터 기록 |
| 4 | MSE 손계산 정확도 | 워크시트 확인 |
| 5 | 레이싱 전략 개선 여부 (1차 vs 2~3차) | 기록 비교 |
| 6 | 순전파 계산 완수 여부 | 시뮬레이터/워크시트 |
| 7 | 토큰화 대결 참여 + 임베딩 탐험 패턴 발견 | 활동 기록 |
| 8 | Temperature 실험 수행 + 환각 사례 1개 이상 발견 | 활동 기록 |

**채점:** 7개 활동 중 완수한 수에 따라 10점 만점 비례 배점

| 완수 활동 수 | 점수 |
|-------------|------|
| 7개 | 10 |
| 6개 | 9 |
| 5개 | 8 |
| 4개 | 7 |
| 3개 | 5 |
| 2개 이하 | 3 이하 |

### 5-2. 서술형 평가 (40점)

문항은 사전 공개하며, 10차시 이후 오프라인 손글씨로 작성한다.

#### 문항 요약

| 유형 | 문항 | 측정 대상 | 원배점 |
|------|------|----------|--------|
| A1 | 활성화함수의 역할 + ReLU vs Sigmoid | 개념 정확성 | 10 |
| A2 | 손실함수의 역할 (학습·최적화 관계) | 개념 정확성 | 10 |
| A3 | 경사하강법 원리 (기울기·학습률·최솟값) | 개념 정확성 | 10 |
| A4 | 활성화함수 3종 이상 + 각 특징 | 개념 정확성 | 10 |
| B1 | 단층 퍼셉트론의 XOR 한계 (좌표평면) | 상황 적용 | 10 |
| B2 | 활성화함수 전체 제거 시 문제 (XOR 예시) | 상황 적용 | 10 |
| C1 | ChatGPT 환각 원인 (토큰화·확률·손실·데이터) | 인과적 종합 | 20 |
| | **합계** | | **80** |

**80점 → 40점 환산:** 서술형 원점수 x 0.5 = 환산 점수

#### 채점 기준 요약 (상세 루브릭은 rubric.mdx 참조)

**A·B유형 (각 10점):**
- 상(9~10): 핵심 개념 정확 + 구체적 예시/비유
- 중(6~8): 대체로 정확, 예시 부족 또는 일부 부정확
- 하(3~5): 일부 개념만 서술 또는 불완전
- 미달(0~2): 미이해 또는 무관한 내용

**C유형 (20점, 항목별 5점):**
- 토큰화 / 확률적 예측 / 손실함수 / 학습 데이터 각 5점
- 4개 개념의 인과적 연결이 있으면 가산, 나열식이면 감점

### 5-3. Before/After 성찰 (10점)

1차시(Before)와 9~10차시(After)에서 같은 질문 "기계가 생각할 수 있는가?"에 대한 답변을 비교한다.

| 평가 항목 | 배점 | 5단계 기준 |
|----------|------|-----------|
| 1차시 답변 회고 | 2 | 과거 답변의 논리와 근거를 구체적으로 재구성(2) ~ 미작성(0) |
| 10차시 답변의 깊이 | 4 | 개념 3개 이상 인과적 연결(4) ~ 미작성(0) |
| 변화 인식 | 2 | 변화의 원인을 분석(2) ~ 미인식(0) |
| 성찰의 진정성 | 2 | 자기 언어로 솔직 서술(2) ~ 형식적 답변(0) |

## 6. 피드백 체계

### 수준별 피드백 방법

| 수준 | 과정 피드백 (수업 중) | 결과 피드백 (평가 후) |
|------|---------------------|---------------------|
| **상** | "~라는 질문이 핵심을 찔렀어요. 더 나아가서 ~도 생각해보세요." | "인과관계 연결이 정확합니다. ~부분의 논거를 더 보강하면 완벽합니다." |
| **중** | "좋은 시도예요. ~개념과 연결해서 다시 생각해보세요." | "핵심 개념은 이해하고 있습니다. ~에 구체적 예시를 추가해보세요." |

## 7. 성적 산출

### 과정평가 40점 산출

| 항목 | 만점 | 산출 방법 |
|------|------|----------|
| 교사 관찰 | 20 | 관찰 차시 평균 점수 → 환산표 적용 |
| 포트폴리오 | 10 | 산출물 수 + 질적 수준 → 상/중/하 환산 |
| 동료 평가 | 10 | 동료 평가 평균 → 환산표 적용 |

### 결과평가 60점 산출

| 항목 | 만점 | 산출 방법 |
|------|------|----------|
| 형성평가 | 10 | 1-8차시 활동 완수 수 → 비례 배점 |
| 서술형 평가 | 40 | 7문항 원점수(80점 만점) x 0.5 |
| Before/After | 10 | 4개 항목 합산 |

### 총점 = 과정평가(40) + 결과평가(60) = 100점

### 등급 산출

#### 절대평가 (성취수준) 기준

| 등급 | 점수 범위 | 설명 |
|------|----------|------|
| A (매우 우수) | 85~100 | 핵심 개념을 정확히 이해하고 인과적으로 연결하여 설명 가능 |
| B (우수) | 70~84 | 핵심 개념을 이해하고 부분적으로 적용 가능 |
| C (보통) | 55~69 | 기본 개념을 이해하나 적용에 어려움 |
| D (노력 필요) | 40~54 | 일부 개념을 이해하나 설명이 불완전 |
| E (미도달) | 0~39 | 핵심 개념의 이해가 부족 |

#### 등급 산출 예시

**예시 1: A등급 학생**
- 교사 관찰 평균 4.5 → 20점
- 포트폴리오 9개 제출 + 구체적 기록 → 10점
- 동료 평가 평균 4.3 → 9점
- 형성평가 7개 완수 → 10점
- 서술형 원점수 74/80 → 37점
- Before/After 9/10 → 9점
- **총점: 95점 (A)**

**예시 2: C등급 학생**
- 교사 관찰 평균 3.2 → 14점
- 포트폴리오 5개 제출 → 6점
- 동료 평가 평균 3.0 → 7점
- 형성평가 4개 완수 → 7점
- 서술형 원점수 42/80 → 21점
- Before/After 5/10 → 5점
- **총점: 60점 (C)**

### 생활기록부 기재문

**상 수준:**
인공지능의 핵심 원리(퍼셉트론, 활성화함수, 손실함수, 경사하강법, 역전파, 토큰화, 임베딩, 어텐션)를 정확히 이해하고, 각 개념을 인과적으로 연결하여 ChatGPT의 환각 현상을 구조적으로 설명함. 수업 활동에 적극적으로 참여하여 창의적 질문을 제기하고 동료 학습에 기여함.

**중 수준:**
인공지능의 주요 개념(활성화함수, 손실함수, 경사하강법 등)을 이해하고 서술형 평가에서 핵심 개념을 활용하여 답변을 작성함. 시뮬레이터 활동과 모둠 토의에 성실히 참여하며, AI의 작동 원리에 대한 기본적인 이해를 보여줌.

**하 수준:**
인공지능 기초 수업에 참여하여 퍼셉트론, 활성화함수, 손실함수 등 기본 개념을 접함. 시뮬레이터 활동을 통해 신경망의 학습 과정을 체험하고, AI의 한계에 대한 기초적인 인식을 갖춤.
