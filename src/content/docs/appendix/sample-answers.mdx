## A유형: 개념 설명형 (각 10점)

### A1. 활성화함수의 역할 + ReLU vs Sigmoid

:::tip[상 수준 예시 답안 (9~10점)]
활성화함수는 신경망에 **비선형성**을 부여하는 장치입니다. 활성화함수가 없으면 층을 아무리 쌓아도 전체 네트워크는 하나의 선형 변환(직선)과 같아서, XOR처럼 직선 하나로 나눌 수 없는 패턴을 학습할 수 없습니다. 활성화함수가 "공간을 구부려주기" 때문에, 여러 층을 쌓으면 복잡한 비선형 패턴도 표현할 수 있게 됩니다.

**ReLU**는 max(0, x)로, 음수 입력은 0으로 만들고 양수는 그대로 통과시킵니다. 계산이 극도로 단순하고, 양수 영역에서 기울기가 항상 1이라 층이 깊어져도 기울기가 사라지지 않습니다.

**Sigmoid**는 모든 값을 0~1 사이로 압축하는 S자 곡선입니다. 출력을 확률처럼 해석할 수 있다는 장점이 있지만, 양 끝에서 기울기가 거의 0이 되어 층이 깊으면 앞쪽 뉴런의 학습이 거의 안 되는 **기울기 소실** 문제가 발생합니다.
:::

:::note[중 수준 예시 답안 (6~8점)]
활성화함수는 신경망이 복잡한 패턴을 학습할 수 있게 해주는 함수입니다. 없으면 직선밖에 표현을 못 합니다. ReLU는 음수면 0, 양수면 그대로인 간단한 함수이고, Sigmoid는 0과 1 사이 값을 출력합니다. Sigmoid는 기울기 소실 문제가 있어서 깊은 신경망에서는 ReLU를 더 많이 씁니다.
:::

:::caution[하 수준 예시 답안 (3~5점)]
활성화함수는 뉴런을 켜고 끄는 역할을 합니다. ReLU와 Sigmoid가 있는데, ReLU가 더 많이 쓰입니다.
:::

### A2. 손실함수의 역할 ("학습"과 "최적화" 포함)

:::tip[상 수준 예시 답안 (9~10점)]
손실함수는 **모델의 예측값과 실제 정답 사이의 차이를 하나의 숫자로 요약하는 함수**입니다. 대표적인 예가 MSE(평균 제곱 오차)로, 각 데이터의 오차를 제곱하여 평균을 낸 것입니다. 오차를 제곱하는 이유는 양수·음수 오차가 상쇄되는 것을 막고, 큰 오차를 더 크게 벌주기 위해서입니다.

**학습**이란 이 손실함수의 값을 최소로 만드는 파라미터(가중치, 편향)를 찾아가는 과정입니다. 경사하강법으로 기울기 방향을 따라 한 걸음씩 이동하면서 손실을 줄여나갑니다.

중요한 점은, 손실을 최소화한다는 것이 "정답을 안다"는 것과 같지 않다는 것입니다. AI는 학습 데이터에서의 패턴을 가장 잘 맞추는 파라미터를 찾을 뿐이지, 세상의 진실을 이해하는 것은 아닙니다. 이것이 AI가 환각(hallucination)을 보이는 구조적 원인 중 하나입니다.
:::

:::note[중 수준 예시 답안 (6~8점)]
손실함수는 AI가 얼마나 틀렸는지를 숫자로 나타내는 함수입니다. MSE는 예측값과 정답의 차이를 제곱해서 평균 낸 것입니다. 학습은 이 손실을 최소화하는 과정이고, 경사하강법을 사용합니다.
:::

:::caution[하 수준 예시 답안 (3~5점)]
손실함수는 틀린 정도를 재는 것입니다. 이 값이 작으면 잘 학습된 것입니다.
:::

### A3. 경사하강법의 원리 ("기울기", "학습률", "최솟값" 포함)

:::tip[상 수준 예시 답안 (9~10점)]
경사하강법은 손실함수의 **기울기**(미분값)를 구해서, 손실이 줄어드는 방향으로 파라미터를 조금씩 이동시키는 최적화 방법입니다. 업데이트 규칙은 `새 파라미터 = 현재 파라미터 - 학습률 × 기울기`입니다.

**학습률**은 한 번에 이동하는 크기입니다. 학습률이 너무 크면 최솟값을 지나쳐 발산하고, 너무 작으면 수렴이 느려집니다. 실제 AI 학습에서는 0.001~0.1 사이의 작은 값을 사용합니다.

**최솟값**은 손실이 가장 낮은 지점으로, 이곳에 도달하는 것이 목표입니다. 하지만 전체 최솟값(글로벌 미니마)이 아닌 지역 최솟값(로컬 미니마)에 갇힐 수 있습니다. 이를 해결하기 위해 모멘텀(관성)을 추가하여 작은 웅덩이를 넘어갈 수 있게 합니다.

안개 낀 산에서 발밑의 경사를 더듬어 가장 낮은 곳으로 내려가는 비유가 경사하강법의 핵심입니다.
:::

:::note[중 수준 예시 답안 (6~8점)]
경사하강법은 기울기를 따라 손실이 줄어드는 방향으로 한 걸음씩 이동하는 방법입니다. 학습률이 한 걸음의 크기이고, 너무 크면 안 되고 너무 작아도 안 됩니다. 최종 목표는 손실의 최솟값에 도달하는 것입니다.
:::

:::caution[하 수준 예시 답안 (3~5점)]
기울기를 따라 내려가서 손실을 줄이는 방법입니다.
:::

### A4. 활성화함수 3가지 이상 + 각각의 특징

:::tip[상 수준 예시 답안 (9~10점)]
1. **Sigmoid**: σ(x) = 1/(1+e⁻ˣ). 출력이 0~1 사이로 확률 해석에 유리합니다. 하지만 양 끝에서 기울기가 0에 가까워지는 **기울기 소실** 문제가 있어 깊은 신경망에는 부적합합니다.

2. **Tanh**: 출력이 -1~1 사이로, Sigmoid보다 출력 범위가 넓어 학습이 약간 빠릅니다. 하지만 양 끝에서의 기울기 소실은 마찬가지입니다.

3. **ReLU**: max(0, x). 양수면 그대로, 음수면 0. 계산이 극히 단순하고 양수 영역에서 기울기가 항상 1이라 기울기 소실이 없습니다. 딥러닝의 기본 활성화함수. 단점은 dying ReLU 현상.

4. **Leaky ReLU**: 음수 입력에 대해 아주 작은 기울기(0.01x)를 허용하여 dying ReLU를 방지합니다.
:::

:::note[중 수준 예시 답안 (6~8점)]
Sigmoid는 출력을 0~1로 압축하는 S자 곡선이고, ReLU는 음수면 0이고 양수면 그대로 내보냅니다. Tanh는 -1~1 사이 출력입니다. Sigmoid는 기울기 소실 문제가 있어서 ReLU가 더 많이 쓰입니다.
:::

## B유형: 사고실험형 (각 10점)

### B1. 단층 퍼셉트론이 XOR을 못 푸는 이유

:::tip[상 수준 예시 답안 (9~10점)]
XOR의 4개 데이터를 좌표평면에 찍으면:
- (0,0) = 0 (파랑), (0,1) = 1 (빨강), (1,0) = 1 (빨강), (1,1) = 0 (파랑)

빨간 점은 대각선 방향으로 배치됩니다. 단층 퍼셉트론의 결정 경계는 **직선 하나**입니다. 어떤 기울기와 절편을 선택하든, 직선 하나로는 대각선 방향의 빨간 점 2개를 파란 점 2개로부터 완전히 분리할 수 없습니다.

이것은 XOR이 **선형 분리 불가능**한 문제이기 때문입니다. 이를 극복하려면 **다층 신경망**(직선 2개 이상)과 **활성화함수**(공간을 구부리는 장치)가 필요합니다. 민스키와 파퍼트가 1969년에 이 한계를 수학적으로 증명했고, 이것이 AI 겨울의 원인이 되었습니다.
:::

:::note[중 수준 예시 답안 (6~8점)]
XOR은 빨간 점과 파란 점이 대각선으로 있어서 직선 하나로 나눌 수 없습니다. 직선 2개를 쓰면 되는데, 이것이 다층 신경망의 아이디어입니다.
:::

---

### B2. 활성화함수를 모두 제거하면?

:::tip[상 수준 예시 답안 (9~10점)]
활성화함수를 모두 제거하면, 각 뉴런이 하는 일은 가중합(곱하기와 더하기)뿐입니다. **선형 변환의 합성은 항상 선형 변환**이므로, 100층을 쌓아도 결국 단층 퍼셉트론과 수학적으로 동일합니다.

예: y = 2(3x + 1) + 4 = 6x + 6 — 여전히 직선입니다.

따라서 XOR 같은 비선형 문제를 풀 수 없고, 층을 쌓는 의미가 완전히 사라집니다. 활성화함수가 직선적 결과를 "구부려서" 비선형 변환을 만들고, 이 구부러짐이 누적되어 복잡한 패턴 표현이 가능해집니다. 이것이 딥러닝의 핵심입니다.
:::

## C유형: 종합 서술형 (20점)

### C1. ChatGPT가 환각을 보이는 이유

:::tip[상 수준 예시 답안 (18~20점)]
ChatGPT의 환각은 AI 작동 구조에서 필연적으로 발생하는 현상입니다.

**1. 토큰화:** 사용자 질문은 토큰으로 쪼개집니다. AI에게 "존재하지 않는 논문"이든 "실제 논문"이든 모두 토큰의 나열일 뿐이며, 사실 여부를 판별하는 메커니즘이 없습니다.

**2. 확률적 예측:** AI의 핵심은 "다음 토큰의 확률 분포를 예측하는 것"입니다. 존재하지 않는 논문이라도 "논문 요약" 패턴에 맞는 가장 그럴듯한 토큰들을 연쇄적으로 생성합니다.

**3. 손실함수의 한계:** 손실함수를 최소화하는 것은 학습 데이터의 패턴을 가장 잘 맞추는 것이지, "세상의 진실을 아는 것"이 아닙니다.

**4. 학습 데이터의 한계:** 학습 데이터에 없는 사실에 대해 AI는 "모른다"고 멈추지 않고, 패턴에 기반하여 자연스러운 출력을 생성합니다.

결론적으로, 환각은 "멍청해서"가 아니라 "확률적 다음 토큰 예측 구조이기 때문에" 발생하는 **구조적으로 불가피한 현상**입니다.
:::

:::note[중 수준 예시 답안 (10~17점)]
ChatGPT는 다음 단어를 확률적으로 예측하는 AI입니다. 학습 데이터에 정답이 없어도 가장 그럴듯한 단어를 이어서 만들어냅니다. 토큰화를 거쳐 처리되기 때문에 사실과 거짓을 구별할 수 없고, 손실함수를 줄이는 학습은 진실을 아는 것이 아닙니다.
:::

:::caution[하 수준 예시 답안 (5~9점)]
AI는 학습 데이터에서 배운 패턴으로 다음 단어를 예측하므로, 모르는 것도 그럴듯하게 답합니다.
:::

### 4차시: MSE 손계산 연습

**문제:** 데이터 (1, 4), (2, 5), (3, 8)에 대해 두 직선의 MSE를 비교하시오.

**직선 A: y = 2x + 1**

| 데이터 | 실제값 | 예측값 | 오차 | 오차² |
|--------|-------|--------|------|-------|
| (1, 4) | 4 | 3 | 1 | 1 |
| (2, 5) | 5 | 5 | 0 | 0 |
| (3, 8) | 8 | 7 | 1 | 1 |

MSE = (1 + 0 + 1) / 3 = **0.67**

**직선 B: y = 2.5x + 0.5**

| 데이터 | 실제값 | 예측값 | 오차 | 오차² |
|--------|-------|--------|------|-------|
| (1, 4) | 4 | 3.0 | 1.0 | 1.0 |
| (2, 5) | 5 | 5.5 | -0.5 | 0.25 |
| (3, 8) | 8 | 8.0 | 0 | 0 |

MSE = (1.0 + 0.25 + 0) / 3 = **0.42**

**모범 답안:** 직선 B(MSE 0.42)가 직선 A(MSE 0.67)보다 더 나은 직선입니다. MSE가 더 작으므로 전체적으로 데이터에 더 가깝게 지나갑니다.

### 5차시: 경사하강법 업데이트 계산

**문제:** 현재 w = 5.0, 기울기 = -3일 때 각 학습률에 따른 새 w

| 학습률 | 계산 과정 | 새 w | 해석 |
|--------|----------|------|------|
| 0.1 | 5.0 - 0.1 × (-3) = 5.0 + 0.3 | **5.3** | 안전하지만 느린 이동 |
| 0.5 | 5.0 - 0.5 × (-3) = 5.0 + 1.5 | **6.5** | 적당한 이동 |
| 2.0 | 5.0 - 2.0 × (-3) = 5.0 + 6.0 | **11.0** | 너무 큰 이동, 발산 위험 |

**적절한 학습률:** 0.5. 0.1은 수렴이 느리고, 2.0은 발산 위험.

### 6차시: 순전파 계산

**2-1-1 네트워크 (입력: x₁=1.0, x₂=0.5, 정답: y=1.0)**

| 단계 | 계산 | 결과 |
|------|------|------|
| 은닉 가중합 | z₁ = 0.3×1.0 + 0.7×0.5 + 0.1 | 0.75 |
| 은닉 활성화 | a₁ = σ(0.75) = 1/(1+e⁻⁰·⁷⁵) | ≈ 0.679 |

| 출력 활성화 | ŷ = σ(0.540) | ≈ 0.632 |
| 오차(MSE) | (0.632 - 1.0)² | ≈ 0.135 |
