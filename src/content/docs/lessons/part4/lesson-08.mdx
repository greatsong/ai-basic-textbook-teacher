## 수업 흐름 (시간별 상세 안내)

### 00-03분: 도입 이야기

> "8명의 연구자가 논문 한 편을 썼어요. 제목이 뭐였냐면 — 'Attention Is All You Need', '이것만 있으면 된다.' 이 논문 하나가 AI의 모든 것을 바꿨어요. 번역, 글쓰기, 코딩, 대화 — 전부 이 하나의 아이디어에서 나왔습니다. 그런데 이 AI가 하는 일의 본질은 놀랍도록 단순해요. 다음 단어를 맞추는 것. 그것뿐입니다."

**교사 주의사항:** 8차시는 1~8차시 자기완결 구간의 마지막 차시입니다. 개념 전달뿐 아니라 1~8차시 전체를 하나의 흐름으로 통합하는 것이 핵심입니다.

### 03-18분: 실습 — 다음 단어 예측 게임

**진행 순서:**
1. NextWordPrediction 시뮬레이터를 열게 한다
2. "오늘 점심에 나는 ___을 먹었다" — 학생이 먼저 빈칸 예측 입력
3. AI의 예측을 확률 분포 막대그래프로 확인 (밥 35%, 김치 12%, 피자 8%...)
4. "한국의 수도는 ___이다" — 특정 단어가 압도적 확률을 차지하는 경우
5. Temperature 슬라이더를 조절하며 출력 변화 관찰
6. 존재하지 않는 사실에 대한 질문 → 그럴듯한 답 생성(환각 체험)

**Temperature 실험 가이드:**
| Temperature | 학생이 관찰할 것 |
|-------------|---------------|
| 0.1 (낮음) | "밥"만 반복 → 안전하지만 지루 |
| 1.0 (중간) | 자연스러운 다양한 답 |
| 2.0 (높음) | "우주선", "행복" 같은 엉뚱한 답 → 환각의 직관적 이해 |

**운영 팁:** Temperature 실험이 가장 흥미로운 순간입니다. 학생들이 직접 슬라이더를 만져보며 "이 하나의 값이 AI를 판에 박힌 답변에서 창의적 글쓰기까지 바꿀 수 있다"는 것을 체감하게 하세요.

### 18-35분: 이론 — 확률적 예측, Temperature, 어텐션 아이디어

**설명 순서:**

**1. 핵심 원리 (5분)**
> "AI가 하는 일의 본질은 단 하나: 다음 단어를 맞추는 것. 여러분도 방금 빈칸을 채웠죠? 여러분은 살아오면서 읽고 들은 경험으로, AI는 수십억 개의 텍스트 데이터로 — 같은 일을 합니다."

**2. Temperature 설명 (3분)**
- 로짓(AI가 각 단어에 매긴 원점수)을 Temperature로 나눈 뒤 확률로 변환
- 낮은 Temperature: 점수 차이 극대화 → 1등만 선택
- 높은 Temperature: 점수 차이 축소 → 여러 단어가 비슷한 확률

**3. 어텐션 — "어디를 주목할 것인가" (7분)**
- 비유: 수업 시간 필기에 형광펜 칠하기
- 핵심 예시: "나는 프랑스에서 태어나서... ___를 잘합니다" → "프랑스에서"에 주목해야 "프랑스어" 예측 가능
- "나는 은행에 갔다" vs "강 은행에 꽃이 피었다" → 같은 "은행"이지만 주변 단어에 따라 의미가 다름
- AttentionVisualization 시뮬레이터로 단어 간 연결 강도 시각화

**4. 트랜스포머의 혁신 (2분)**
- 이전(RNN): 문장을 순서대로 한 단어씩 읽음 → 긴 문장에서 앞부분을 잊음
- 트랜스포머: 문장 전체를 한 번에 보면서 어텐션으로 중요한 연결을 찾음

### 35-47분: 이론 심화 — 환각은 왜 생기는가 + 1~8차시 전체 통합

**환각의 구조적 필연성 (7분):**
> "AI는 정답을 아는 게 아니라, 학습 데이터에서 가장 가능성 높은 다음 단어를 고르는 것입니다. 학습 데이터에 정답이 없으면? → 가장 그럴듯한 답을 생성 → 환각. 이것은 버그가 아니라, 구조의 필연적 결과입니다."

**1~8차시 전체 파이프라인 정리 (5분):**

| 단계 | 하는 일 | 배운 차시 |
|------|---------|----------|
| 토큰화 | 문장을 토큰으로 쪼갠다 | 7차시 |
| 임베딩 | 토큰을 의미 벡터로 바꾼다 | 7차시 |
| 어텐션 | 단어 간 관련성을 계산한다 | 8차시 |
| 신경망 처리 | 여러 층을 통과하며 정보 처리 | 2~3차시 |
| 확률 출력 | 다음 토큰의 확률 분포 계산 | 8차시 |
| 학습 | 손실함수 + 역전파 + 경사하강법 | 4~6차시 |

> "이것이 전부입니다. 퍼셉트론이 파라미터 3개로 AND를 배웠던 것과 원리는 같아요. 다른 것은 규모뿐 — GPT-4는 수천억 개의 파라미터입니다."

### 47-50분: 역사 공개 + 마무리

> "'Attention Is All You Need.' 2017년 구글 연구자 8명이 쓴 논문이에요. 인용 횟수 10만 회가 넘습니다. 이 하나의 아이디어에서 GPT-1(2018), GPT-2(2019), GPT-3(2020), 그리고 ChatGPT(2022)가 나왔어요."

**9~10차시가 있는 경우:** "다음 시간에는 오늘까지 배운 모든 개념이 어떻게 역사적으로 이어지는지 전체 지도를 완성합니다."

**8차시로 끝나는 경우:** "기계가 생각할 수 있는가? — 1차시에서 이 질문을 처음 만났죠. 이제 여러분은 AI의 내부를 알고 있습니다. 이 질문에 대한 여러분의 답이 달라졌나요?"

## 교사 발화 예시

### 다음 단어 예측 게임 직후 — 핵심 통찰

> "여러분의 예측과 AI의 예측이 비슷한 경우가 많았죠? 여러분도 AI도 같은 것을 하고 있기 때문이에요. 차이가 있다면, 여러분은 세상에 대한 경험과 이해를 바탕으로 예측하지만, AI는 오직 텍스트 패턴만을 바탕으로 예측한다는 점입니다."

### 어텐션 설명 — 비유 전개

> "수업 시간에 선생님이 '여기 중요합니다'라고 한 부분에 형광펜을 칠하는 것 — 이게 어텐션이에요. 모든 곳에 형광펜을 칠하면 의미가 없겠죠. 관련 있는 단어끼리 강하게 연결하고, 관련 없는 건 무시하는 것."

### 환각 설명 — 충격 전달

> "여러분이 방금 AI에게 존재하지 않는 논문을 물어봤을 때, AI가 자신있게 요약을 해줬죠? 이건 AI가 멍청해서가 아니에요. 메커니즘 자체가 '가장 그럴듯한 다음 단어를 고르는 것'이니까, 모르는 질문에도 그럴듯한 답을 만들어낼 수밖에 없는 거예요."

### 전체 통합 — 감동적 마무리

> "2차시에서 퍼셉트론이 파라미터 3개로 AND를 배웠던 것, 기억하나요? 오늘 배운 ChatGPT도 원리는 정확히 같아요. 다른 것은 규모뿐입니다. 1~8차시에서 배운 모든 개념 — 퍼셉트론, 활성화함수, 손실함수, 경사하강법, 역전파, 토큰화, 임베딩, 어텐션 — 이것이 전부 하나의 시스템 안에 들어 있습니다."

## 시뮬레이터 운영 가이드

### NextWordPrediction (다음 단어 예측기)
- **소요 시간:** 약 12-15분
- **주요 기능:** 문장 입력 → 다음 단어 확률 분포 막대그래프, Temperature 슬라이더
- **교사 팁:** 첫 번째 문장("오늘 점심에 나는 ___을 먹었다")은 교사가 시연하고, 이후 학생 자유 입력. "한국의 수도는 ___이다" 같은 사실 질문과 "존재하지 않는 논문" 질문을 반드시 포함하세요.
- **Temperature 실험 순서:** 1.0 → 0.1 → 2.0 순서로 보여주면 대비 효과가 큽니다.
- **주의사항:** 학생들이 부적절한 문장을 입력할 수 있으므로, "학습 목적으로 사용"을 사전에 안내합니다.

### AttentionVisualization (어텐션 시각화기)
- **소요 시간:** 약 5-7분
- **주요 기능:** 문장 내 단어 간 어텐션 연결 강도를 선 굵기/색상으로 시각화
- **교사 팁:** "은행" 예시를 두 문장으로 비교하면 어텐션의 역할이 명확해집니다. 학생들에게 "어떤 단어끼리 강하게 연결되어 있나요?"라고 질문하세요.

## 학생 예상 질문 & 답변

**Q1. 다음 단어를 맞추는 것만으로 어떻게 대화가 가능한가요?**
> "한 단어를 예측하면, 그 단어를 입력에 추가하고 다시 다음 단어를 예측합니다. 이것을 반복하면 문장이 되고, 문단이 되고, 대화가 됩니다. 한 글자씩 받아쓰기하는 것과 비슷해요."

**Q2. Temperature를 0으로 하면 항상 같은 답이 나오나요?**
> "Temperature가 0에 가까우면 확률이 가장 높은 단어만 항상 선택되므로, 같은 입력에 대해 거의 같은 출력이 나옵니다. 실제 ChatGPT에서 '창의적 글쓰기'와 '코드 생성' 모드의 차이가 Temperature 설정에서 옵니다."

**Q3. 어텐션은 사람의 '집중'과 같은 건가요?**
> "비슷한 비유이지만 정확히 같지는 않아요. 사람의 집중은 의식적이지만, AI의 어텐션은 수학적으로 계산된 '관련성 점수'입니다. 각 단어 쌍의 관련 정도를 숫자로 계산하는 것이에요."

**Q4. 환각을 완전히 없앨 수 있나요?**
> "다음 토큰을 확률적으로 예측하는 구조가 바뀌지 않는 한, 완전히 없앨 수는 없어요. 추가 학습으로 줄일 수는 있지만, 구조적 가능성은 항상 남습니다. 이것이 AI를 사용할 때 사실 확인이 중요한 이유예요."

**Q5. GPT-4는 파라미터가 몇 개인가요?**
> "정확히 공개되지 않았지만, 추정 수천억~수조 개입니다. 2차시에서 본 퍼셉트론이 파라미터 3개였던 것과 비교하면, 원리는 같지만 규모가 상상을 초월하죠."

**Q6. 트랜스포머 이전의 RNN은 왜 잊어버리나요?**
> "RNN은 단어를 순서대로 처리하면서, 앞 단어의 정보를 '요약'해서 다음으로 넘깁니다. 요약을 반복하면 정보가 점점 손실되는 거예요. 트랜스포머는 전체를 한 번에 보기 때문에 이 문제가 없습니다."

## 평가 포인트

| 평가 항목 | 상 | 중 | 하 |
|---------|---|---|---|
| 다음 단어 예측 이해 | AI의 핵심 원리가 "다음 토큰의 확률 분포 예측"임을 설명하고, 구체적 예시 제시 | "다음 단어를 맞추는 것"이라고 설명 | "AI가 문장을 이해한다" 수준 |
| Temperature 이해 | Temperature에 따른 출력 변화를 설명하고, 용도별 설정의 의미를 연결 | Temperature가 다양성을 조절한다는 것을 아는 수준 | Temperature의 역할을 설명 못함 |
| 환각의 구조적 이해 | 환각이 "확률적 예측 구조"의 필연적 결과임을 수업 개념과 연결하여 설명 | "AI가 모르는 것도 답한다"고 설명 | "AI가 멍청해서 틀린다" 수준 |
| 전체 파이프라인 | 1~8차시의 개념을 하나의 흐름(토큰화→임베딩→어텐션→신경망→학습)으로 연결 | 일부 개념의 연결을 설명 | 각 차시를 독립적으로만 이해 |

## 폴백 계획 (기술 장애 시 대안 활동)

**시나리오 1: 시뮬레이터 전체 접속 불가**
- "다음 단어 예측 게임" 오프라인 버전: 교사가 칠판에 "오늘 날씨가 ___" 같은 문장을 적고, 학생들이 A4 용지에 예측 단어 3개와 확률(%)을 적어 제출. 학급 전체 결과를 집계하여 "우리 반의 확률 분포"를 칠판에 막대그래프로 그림
- 어텐션 설명: "은행" 예시를 칠판에 두 문장 적고, "어떤 단어가 '은행'의 의미를 결정하는 데 중요한가?" 모둠 토의
- Temperature: "시험에서 확실한 답만 쓰는 학생 vs 감으로 엉뚱한 답을 쓰는 학생" 비유로 설명

**시나리오 2: 일부 학생 접속 장애**
- 접속 가능한 학생과 2인 1조 구성
- Temperature 실험은 교사 화면을 프로젝터로 시연

**시나리오 3: 시뮬레이터는 되지만 응답이 느릴 때**
- 입력 문장 수를 제한하고 (학생당 3문장), 핵심 실험에 집중
- 교사가 미리 캡처해둔 결과 화면으로 보충 설명

## 차시 연결

### 이전 차시 복습 포인트 (7차시 → 8차시)
> "지난 시간에 토큰화로 문장을 쪼개고, 임베딩으로 의미가 담긴 숫자 벡터로 바꾸는 것을 배웠어요. 글자를 숫자로 바꾸는 다리를 놓은 거죠. 이제 마지막 퍼즐 — AI는 이 숫자들로 정확히 무엇을 하는 걸까요?"
