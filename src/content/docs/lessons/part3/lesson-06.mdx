## 도입 이야기 가이드 (00-03분)

### 배경 지식: 교사가 알아두면 좋은 것

**역전파(Backpropagation)의 역사**
- 핵심 아이디어: 출력의 오차를 입력 방향으로 거꾸로 추적하면서, 각 가중치가 오차에 "얼마나 책임이 있는지"를 계산
- 수학적 기초: 합성함수의 연쇄법칙(Chain Rule) — "최종 결과의 변화 = 각 단계 변화의 곱"
- 1970년대: 핀란드의 세포 린나인마(Linnainmaa)가 자동 미분에서 유사 아이디어 제시
- 1974년: 폴 워보스(Paul Werbos)가 박사논문에서 신경망에 적용 제안 → 거의 주목받지 못함
- 1986년: 럼멜하트(Rumelhart), 힌튼(Hinton), 윌리엄스(Williams)가 Nature 논문으로 발표 → 학계 전체의 관심
- 이 알고리즘 덕분에 2층 이상의 신경망도 학습 가능 → 딥러닝의 문을 연 핵심 기술

**학생에게 어느 정도까지 말할 것인가:**
- 1986년 Nature 논문, 세 사람의 이름 → 역사 공개 파트에서 (수업 마지막)
- 연쇄법칙의 수식 → 심화 학생에게만 (교과서 심화 박스 참조)
- "오차의 책임을 거꾸로 추적" → 핵심 직관, 반드시 전달
- 기울기 소실(vanishing gradient) → 3차시 ReLU와 연결 가능한 심화 내용

### 교사 멘트

> "이 논문이 나오기 전에는, 신경망이 3층만 넘어가도 학습이 안 됐어요. 1층, 2층은 되는데 3층부터는 뒤쪽 가중치가 거의 안 바뀌는 거예요."

> "연구자 세 명이 해결한 방법은 놀랍도록 직관적이었어요. '오차를 거꾸로 보내자.' 오늘 여러분은 그 과정을 숫자 하나하나까지 직접 따라가게 됩니다."

### 학생 예상 반응

| 반응 | 대응 |
|------|------|
| "역전파가 뭔데요?" | "이름만 들으면 어려운데, 하나씩 따라가면 생각보다 직관적이에요. 먼저 숫자를 따라가봅시다." |
| "이건 어렵겠다..." | "실은 사칙연산밖에 안 써요. 계산기도 쓸 수 있고요. 직접 해보면 '별거 아니네' 할 거예요." |
| "5차시에서 한 거랑 뭐가 달라요?" | "5차시는 '어디로 가야 하는지' 알았을 때 움직이는 방법이었어요. 오늘은 그 '어디로'를 구하는 방법이에요." |

**주의:** 학생들이 "이건 어렵겠다"는 선입견을 가질 수 있습니다. 도입에서 "거꾸로 보내자"라는 아이디어가 직관적임을 강조하세요. 축제 비유를 적극 활용합니다.

## Phase 1~2: 순전파 직접 계산 + 오차 계산 가이드 (03-20분)

### 교사 멘트 — 동기 유발

> "지난 시간에 경사하강법을 배웠죠. 기울기를 따라 한 걸음씩 내려가면 손실을 줄일 수 있다고요. 그런데 한 가지 빠진 이야기가 있었어요. 파라미터가 하나일 때는 괜찮은데, 층이 여러 개인 신경망에서는 어떻게 기울기를 구하죠?"

> "출력에서 나온 오차를 가지고, 깊이 묻혀 있는 첫 번째 층의 가중치까지 기울기를 어떻게 전달할까요?"

### 순전파 계산 진행

**진행 방식:**
1. 교과서의 ForwardPassCalculator 시뮬레이터를 연다
2. 2-1-1 네트워크의 구조를 판서로 먼저 설명한다 (입력 2개 → 은닉 1개 → 출력 1개)
3. 학생이 직접 가중합을 계산하여 입력란에 입력한다
4. 정답이면 다음 단계, 오답이면 힌트 제공

#### 교사 멘트 — 계산 안내

> "지금부터 아주 작은 신경망을 손으로 돌려봅니다. 입력 2개, 은닉 뉴런 1개, 출력 1개. 2-1-1 네트워크예요."

(칠판에 네트워크 구조를 그리며)

> "각 뉴런이 하는 일을 따라가 봅시다. 계산기 써도 됩니다. 중요한 건 계산 속도가 아니라, '뉴런이 숫자를 어떻게 처리하는가'를 느끼는 거예요."

### 핵심 숫자 (학생이 따라가야 할 계산)

| 단계 | 계산 | 결과 |
|------|------|------|
| 은닉 뉴런 가중합 | z₁ = 0.3 x 1.0 + 0.7 x 0.5 + 0.1 | **0.75** |
| Sigmoid 통과 | a₁ = σ(0.75) = 1 / (1 + e^(-0.75)) | **≈ 0.679** |
| 출력 뉴런 가중합 | z₂ = 0.5 x 0.679 + 0.2 | **≈ 0.540** |
| 출력 | ŷ = σ(0.540) | **≈ 0.632** |
| 오차(MSE) | (0.632 - 1.0)² | **≈ 0.135** |

### 학생 예상 반응 (계산 중)

| 반응 | 대응 |
|------|------|
| "Sigmoid가 뭐였죠?" | "3차시에서 배운 활성화함수예요. 1/(1+e^(-x)). 계산기로 구해봅시다." |
| "e^(-0.75)를 어떻게 구해요?" | "계산기에서 e^x 버튼을 찾으세요. -0.75를 넣으면 약 0.4724가 나와요. 그러면 1/(1+0.4724) = 0.679예요." |
| "계산이 맞는지 어떻게 알아요?" | "시뮬레이터에 숫자를 입력하면 맞는지 바로 알려줘요." |
| "이걸 왜 손으로 해요?" | "여러분이 방금 한 것은 뉴런이 하는 일을 그대로 따라한 겁니다. AI가 대단해 보이지만, 한 뉴런이 하는 일은 사칙연산이에요." |

#### 교사 멘트 — 계산 완료 후

> "계산이 맞았어요! 여러분이 방금 한 것은 뉴런이 하는 일을 그대로 따라한 겁니다. AI가 대단해 보이지만, 한 뉴런이 하는 일은 사칙연산이에요."

> "정답은 1.0인데, 이 신경망은 0.632라고 답했어요. 오차가 0.135예요. 이 오차를 줄이려면, **어떤 가중치를 바꿔야 할까요?**"

### 시뮬레이터 운영 상세: ForwardPassCalculator

| 항목 | 내용 |
|------|------|
| **소요 시간** | 약 12-15분 |
| **주요 기능** | 학생이 가중합, 활성화함수 결과, 오차를 직접 계산하여 입력 |
| **교사 팁** | 첫 번째 가중합 계산에서 막히는 학생이 많습니다. "w₁ x x₁ + w₂ x x₂ + b₁ 을 대입해보세요"라고 구체적으로 안내하세요. |
| **자주 발생하는 오류** | Sigmoid 계산에서 e^(-0.75)를 구할 때 계산기 사용법을 모르는 경우 → "1 / (1 + 0.4724)" 형태로 안내 |

**운영 팁:** 계산이 느린 학생에게는 "계산기 사용 OK"를 먼저 안내하세요. 중요한 것은 계산 속도가 아니라 "뉴런이 숫자를 어떻게 처리하는가"를 체험하는 것입니다.

## Phase 3: 역전파 애니메이션 + 이론 가이드 (20-35분)

### 교사 멘트 — 예측 유도

> "이 오차 0.135를 줄이려면, 어떤 가중치를 바꿔야 할까? 가중치가 세 개 있어요. w₁, w₂, w₃."

> "여기서 질문. **어떤 가중치가 오차에 대한 책임이 가장 클 것 같아요?** w₁? w₂? w₃? 손 들어봅시다."

**3~4명의 예측을 반드시 받으세요.** "왜 그렇게 생각하는지"도 한두 명에게 물어보세요. 이 예측이 역전파 결과와 비교되면서 학습 효과가 극대화됩니다.

### 학생 예상 반응 (예측 단계)

| 반응 | 대응 |
|------|------|
| "w₃가 제일 크지 않아요? 출력에 제일 가까우니까" | "좋은 직관이에요! 맞는지 확인해봅시다." |
| "w₁이요. 입력이니까" | "그럴 수도 있어요. 입력이 처음이니까 영향이 클 수 있다고 생각할 수 있죠. 확인해봅시다." |
| "다 똑같지 않아요?" | "그럴 수도 있죠. 하지만 실제로는 책임이 다릅니다. 확인해보면 놀라실 거예요." |

### 역전파 핵심 직관 전달

#### 교사 멘트

> "역전파의 아이디어는 이거예요. 최종 오차가 0.135였다고 합시다. 이 오차에 대해 **각 가중치가 얼마나 책임이 있는지**를 거꾸로 추적하는 겁니다. 출력에 가까운 가중치는 책임이 크고, 입력에 가까운 가중치는 책임이 작을 수 있어요."

> "학교 축제 공연이 실패했을 때를 떠올려 보세요. 무대 위에서 직접 공연한 학생의 책임은 분명하죠? 그런데 한 달 전에 곡을 선정한 학생은요? 음향 담당은요? 최종 실패에 대한 세 사람의 '책임'은 다릅니다. 역전파는 이 '책임 추적'을 수학적으로 정확하게 하는 방법이에요."

### 역전파 애니메이션 시연

**진행 순서:**
1. BackpropAnimation 시뮬레이터를 프로젝터에 띄운다
2. "역전파 시작" 버튼을 누른다
3. 빨간 오차 신호가 역방향으로 이동하는 것을 관찰하게 한다
4. 각 가중치의 업데이트 전후 값("0.30 → 0.27")을 비교하게 한다

#### 교사 멘트 — 애니메이션 중

> "보세요. 빨간색 오차 신호가 출력에서 입력 방향으로 거꾸로 이동하고 있어요."

> "가중치 옆에 숫자가 바뀌고 있죠? '0.30 → 0.27'처럼. **어떤 가중치가 더 많이 바뀌었는지** 관찰하세요. 여러분의 예측과 맞나요?"

> "w₃가 가장 많이 바뀌었죠? 출력에 가까울수록 책임이 크니까요. 방금 예측한 학생들, 맞았어요?"

### BackpropToggle (ON/OFF 비교) 시연

#### 교사 멘트

> "이번에는 역전파를 껐다 켰다 해볼게요."

> "먼저 역전파 OFF 상태에서 학습 버튼을 10번 누르세요. 은닉층의 가중치가 어떻게 되는지 보세요."

(학생이 실행)

> "은닉층 가중치가 거의 안 바뀌죠? 출력층만 바뀌어요. 왜 그럴까요? — 오차 신호가 출력층까지만 가고, 은닉층까지 전달이 안 되기 때문이에요."

> "이제 역전파를 ON으로 바꾸고 다시 10번 눌러보세요."

> "이번에는 모든 층의 가중치가 바뀌죠? 오차 신호가 거꾸로 전달되면서 **은닉층의 가중치도 업데이트**됩니다. 이것이 역전파의 위력이에요."

### 학생 예상 반응 (역전파 시연 후)

| 반응 | 대응 |
|------|------|
| "역전파는 왜 앞으로가 아니라 뒤로 계산하나요?" | "신경망은 '함수 안의 함수' 구조(합성함수)입니다. 출력의 오차를 입력 방향으로 분해하려면, 출력부터 거꾸로 풀어나가는 것이 가장 효율적이에요. 마치 실타래가 엉켜 있을 때 끝에서부터 풀어가는 것처럼요." |

## 폴백 계획 (기술 장애 시 대안 활동)

### 시나리오 A: 시뮬레이터 전체 접속 불가

**대안 활동 — 종이 + 계산기 순전파 (20분)**

1. 칠판에 2-1-1 네트워크를 그린다
2. 학생들에게 종이 + 계산기로 순전파 계산을 수행하게 한다
3. 가중합 → Sigmoid → 오차까지 직접 계산하는 워크시트를 배포한다
4. 역전파는 "출력 가중치 w₃의 책임이 가장 크다"는 직관적 설명으로 대체한다
5. "책임의 크기에 비례해서 가중치를 수정한다"는 핵심만 전달

**워크시트 예시:**
```
[순전파 계산 워크시트]
입력: x₁ = 1.0, x₂ = 0.5
가중치: w₁ = 0.3, w₂ = 0.7, b₁ = 0.1, w₃ = 0.5, b₂ = 0.2

Step 1. 은닉 뉴런 가중합: z₁ = w₁ x x₁ + w₂ x x₂ + b₁ = ___
Step 2. Sigmoid 통과: a₁ = 1 / (1 + e^(-z₁)) = ___
Step 3. 출력 뉴런 가중합: z₂ = w₃ x a₁ + b₂ = ___
Step 4. 출력: ŷ = 1 / (1 + e^(-z₂)) = ___
Step 5. 오차(MSE): (ŷ - 1.0)² = ___
```

### 시나리오 B: 일부 학생 접속 장애

- 접속 가능한 학생 화면을 2인 1조로 공유한다
- 한 명이 시뮬레이터를 조작하고, 다른 한 명이 계산을 검증하는 역할 분담

### 시나리오 C: 시뮬레이터는 되지만 속도가 느릴 때

- 순전파 계산 부분만 시뮬레이터 사용
- 역전파 애니메이션은 교사 화면을 프로젝터로 시연
- BackpropTrainer의 반복 학습은 교사가 대표로 실행하며 학생이 관찰

### 보충 자료
- 기울기 소실(Vanishing Gradient): Sigmoid의 미분값 최대 0.25가 층마다 곱해져서, 5~6층만 넘어가도 기울기가 거의 0에 수렴. 이것이 ReLU(3차시)가 필수인 이유. 학생이 질문하면 "Sigmoid의 한계"로 간결하게 설명.
- 연쇄법칙(Chain Rule): 교과서 심화 박스에 수식이 있음. 학생이 수식을 보고 질문하면 "환율 비유"로 설명하세요.
