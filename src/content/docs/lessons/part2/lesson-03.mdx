### 실험 설계

**활성화함수 토글 시뮬레이터 (ActivationToggle)**

| 항목 | 내용 |
|------|------|
| **사용 시점** | 실습1 (05-20분) |

## 이론 설명 가이드 (슬라이드 #10~14)

### 핵심 흐름

실습에서 "스위치 하나 켰을 뿐인데 된다"는 경험을 한 직후이므로, 학생의 궁금증이 최고조입니다. 이 궁금증을 이론으로 연결하는 구간. **"왜 활성화함수가 없으면 안 되는가"부터 시작하세요.**

### 배경 지식: 교사가 알아두면 좋은 것

**왜 활성화함수 없이 층을 쌓으면 안 되는가**
- 선형 함수의 합성은 항상 선형: y = w₂(w₁x + b₁) + b₂ = (w₂w₁)x + (w₂b₁ + b₂) → 직선 하나
- 10층을 쌓아도, 100층을 쌓아도 곱하기와 더하기의 반복이면 결과는 항상 직선
- 활성화함수가 하는 일: 각 층의 결과를 **비선형적으로 변환** → 층을 쌓는 의미가 생김
- 비유: 종이를 접으면 직선으로 나눌 수 없던 패턴이 나눠진다 (공간을 구부리는 것)

**활성화함수 4종 비교**

| 함수 | 수식 | 출력 범위 | 핵심 특징 | 등장 시기 |
|------|------|----------|---------|----------|
| 계단 함수(Step) | 0 or 1 | {0, 1} | 미분 불가능 → 다층 학습 불가 | 1958 (로젠블랫) |
| Sigmoid | 1/(1+e^(-x)) | (0, 1) | 미분 가능! 하지만 기울기 최대 0.25 | 1986 (역전파에 적용) |
| Tanh | (e^x - e^(-x))/(e^x + e^(-x)) | (-1, 1) | 음수 표현 가능, 여전히 기울기 소실 | 1990년대 |
| ReLU | max(0, x) | [0, +inf) | 계산 극도로 단순, 기울기 소실 없음 | 2012 (AlexNet) |

**기울기 소실 문제 (Vanishing Gradient)**
- Sigmoid의 미분값(기울기) 최대 0.25
- 역전파는 이 기울기를 층마다 곱해서 전달
- 3층: 0.25 x 0.25 x 0.25 = 0.016 → 앞쪽 가중치는 거의 학습 안 됨
- 5층: 0.25^5 = 0.00098 → 사실상 학습 불가능
- ReLU는 양수 영역에서 기울기가 항상 1 → 기울기 소실 없음 → "딥"러닝 가능

**dying ReLU 문제**
- ReLU는 음수 입력이면 출력 0, 기울기도 0
- 가중치가 업데이트되어 항상 음수만 받게 되면 → 영원히 0만 출력 → "죽은 뉴런"
- 해결책: Leaky ReLU (음수 영역에서 아주 작은 기울기), GELU 등
- 학생에게는 "이런 문제도 있다" 정도로만 언급

### 교사 멘트 — "왜 층만 쌓으면 안 되는가"

(슬라이드 #10)

> "방금 확인했죠. 활성화함수 없이 층을 쌓으면, 아무리 쌓아도 안 됩니다. 왜일까요?"

> "이유는 놀랍도록 단순해요. 곱하기와 더하기를 아무리 반복해도 직선이에요."

> "예를 들어, 1층이 '입력을 2배 하고 1을 더하는 것'이고, 2층이 '입력을 3배 하고 4를 더하는 것'이라면 — 2층의 결과는? 6배 하고 7을 더하는 것. 여전히 직선이에요."

> "10층을 쌓아도, 100층을 쌓아도 마찬가지입니다. 직선의 합성은 항상 직선."

### 교사 멘트 — "활성화함수가 하는 일"

(슬라이드 #11)

> "활성화함수가 하는 일은 딱 하나예요 — 직선적인 결과를 구부려주는 거예요."

> "공간을 구부려놓으면 직선으로 나눌 수 없던 패턴도 나눌 수 있게 됩니다."

> "종이 위에 빨간 점과 파란 점이 대각선으로 번갈아 놓여있다고 생각해보세요. 직선으로는 나눌 수 없죠. 그런데 종이를 접으면? 접은 뒤에는 직선 하나로 나눌 수 있게 될 수 있어요. 활성화함수가 이 '접기'를 해주는 거예요."

### 교사 멘트 — 4종 비교

(슬라이드 #12~13)

> "활성화함수에도 종류가 있어요. 역사순으로 봅시다."

> "계단 함수 — 2차시의 퍼셉트론이 사용한 거예요. 0 아니면 1. 중간이 없어요. 중간이 없으면 미분이 불가능하고, 미분이 불가능하면 여러 층의 학습이 안 됩니다."

> "Sigmoid — 부드러운 S자 곡선이에요. 미분이 가능해졌어요! 그래서 여러 층을 학습시킬 수 있게 됐습니다. 하지만 문제가 있어요."

(슬라이드 #14 — 기울기 소실)

> "Sigmoid의 기울기는 최대 0.25예요. 층이 3개면 0.25 x 0.25 x 0.25 = 0.016. 앞쪽 뉴런은 거의 학습이 안 되는 거예요. 이걸 '기울기 소실'이라고 합니다."

> "ReLU는 놀랍도록 단순해요. 음수면 0, 양수면 그대로. max(0, x). 이 단순한 함수가 딥러닝을 가능하게 만든 핵심 중 하나였습니다. 왜냐면 양수 영역에서 기울기가 항상 1이라, 층이 깊어도 학습 신호가 사라지지 않거든요."

### 학생 예상 반응 (이론 설명 중)

| 반응 | 대응 |
|------|------|
| "왜 층을 쌓기만 하면 안 돼요?" | "곱하기와 더하기만 반복하면 결과가 항상 직선이에요. 2x+1을 3배 하고 4를 더하면 6x+7 — 여전히 직선이죠." |

## 역사 공개 가이드 (슬라이드 #18~21)

### 핵심 흐름

도입에서 "혼자 버틴 연구자"를 예고했으니, 이제 그 정체를 밝히는 구간. 실습에서 "활성화함수 하나로 불가능이 가능해졌다"는 경험을 한 직후이므로, 역사와의 연결이 자연스럽습니다.

### 배경 지식: 교사가 알아두면 좋은 것

**제프리 힌튼 (Geoffrey Hinton, 1947-)**
- 영국 출신, "딥러닝의 아버지"
- 고조부: 조지 부울 — AND, OR, NOT의 수학적 토대(부울 대수)를 만든 사람
- 외가 쪽: 조지 에버리스트 — 에베레스트산의 이름이 된 측량사
- 1970-80년대: "신경망은 끝났다"는 학계 분위기 속에서 혼자 연구 지속
- 군사 연구비(DARPA) 거부 → 캐나다 토론토 대학으로 이주
- 1986년: 럼멜하트, 윌리엄스와 함께 역전파 논문 발표 (*Nature*)
- 2006년: 딥 빌리프 네트워크 → "딥러닝"이라는 이름의 시작
- 2012년: 제자들과 AlexNet 개발 → 이미지 인식 대회 압도
- 2024년: 노벨 물리학상 수상

**AlexNet (2012)**
- 힌튼의 제자 알렉스 크리제프스키와 일리아 수츠케버(이후 OpenAI 공동 창립자)가 제작
- ImageNet 대회 오류율 16.4% (2위 26.2%와 10%포인트 차이)
- 핵심 비결: ReLU 활성화함수 + GPU(게임용 그래픽카드 GTX 580 2장)
- 이 이후 컴퓨터 비전 분야가 전부 딥러닝으로 전환

**학생에게 어느 정도까지 말할 것인가:**
- 힌튼이 혼자 버텨낸 것, 노벨상을 받은 것 → 반드시 말하기
- 부울과의 가계 연결 → 관심 있는 학생에게 (2차시 AND/OR과 연결)
- 수츠케버가 OpenAI 공동 창립자라는 것 → "여러분이 쓰는 ChatGPT의 핵심 인물"
- GPU 이야기 → "게임용 그래픽카드로 AI를 만들었다" (학생 관심 유도)

## 폴백 계획 (기술 장애 시 대안 활동)

### 시나리오 A: 시뮬레이터 전체 장애

**대안 활동 — 활성화함수 손 계산 체험 (25분)**

1. 칠판에 2-2-1 네트워크를 그리고 XOR 데이터를 제시
2. 활성화함수 없이(선형만) 순전파 계산을 학생과 함께 수행
   - 1층: h₁ = w₁x₁ + w₂x₂ + b₁, h₂ = w₃x₁ + w₄x₂ + b₂
   - 2층: y = w₅h₁ + w₆h₂ + b₃
   - 전개하면 y = (w₅w₁+w₆w₃)x₁ + (w₅w₂+w₆w₄)x₂ + ... → "결국 직선 하나"를 확인
3. ReLU (max(0, x))를 추가하고 같은 계산을 수행 → 결과가 달라지는 것을 확인
4. 교과서의 "심화: 공간을 구부린다는 것의 수학적 의미" 표를 함께 따라가며 좌표 변환 과정 확인
5. 모눈종이에 변환 전/후 좌표를 직접 찍어보기

### 시나리오 B: 일부 시뮬레이터만 작동

- **ActivationToggle만 작동하면** → 실습1에 집중 (ON/OFF 비교가 핵심). 이것만으로도 3차시의 핵심 경험 전달 가능
- **NetworkBuilder가 작동하지 않으면** → 교사 시연 + 구두 설명으로 대체. 파라미터 카운팅은 칠판에 표로 그려서 비교
- **ActivationComparison만 작동하면** → 4종 비교에 집중. 기울기 소실 개념을 그래프로 직접 확인하게 하세요

### 시나리오 C: 인터넷 전체 장애

**대안 활동 — 종이접기 비선형성 체험 (15분)**

1. A4 종이에 빨간/파란 점 4개를 XOR 패턴으로 찍기
2. 직선을 그어서 나눠보기 → 불가능 확인
3. 종이를 접어서(비선형 변환) 같은 색 점이 같은 쪽으로 오게 만들기
4. 접은 상태에서 직선을 그으면 나눌 수 있다는 것을 체험
5. "활성화함수 = 종이를 접는 것"이라는 비유로 연결

## 차시 연결

### 이전 차시 (2차시) 복습 포인트

> "지난 시간에 퍼셉트론으로 AND, OR은 풀었는데 XOR은 안 됐죠. 직선 하나로는 한계가 있었어요. '직선을 여러 개 쓰면 되잖아'라고 했는데, 오늘 그게 생각만큼 간단하지 않다는 걸 발견합니다."

- 2차시의 XOR 좌절 → 3차시의 활성화함수 발견으로 이어지는 내러티브가 핵심
- "직선 2개 쓰면 된다"의 아이디어가 활성화함수 없이는 작동하지 않는다는 것을 체험
- 2차시 "틀리면 고치고, 맞으면 냅둔다" → 3차시 "그런데 여러 층에서는 어떻게 고치나?" → 역전파 복선

### 다음 차시 (4차시) 예고 포인트

> "오늘 활성화함수로 XOR을 풀고, AlexNet이 이미지 인식 대회를 압도한 이야기를 했어요. AlexNet의 오류율이 16.4%라고 했는데 — 이 숫자는 대체 어떻게 계산한 걸까요? '더 낫다'는 걸 어떻게 숫자로 표현할까요? 다음 시간에 그 이야기를 합니다."

**교사 메모:** 3차시의 "스위치 하나로 불가능이 가능으로" 경험은 학생들에게 강한 인상을 남깁니다. 이 경험을 4차시의 "틀린 정도를 숫자로 재는 법"과 연결할 때, "활성화함수를 켜면 오류가 줄어든다 → 그 '오류'를 정확히 어떻게 측정하는가?"로 자연스럽게 이어주세요. 3차시에서 AlexNet 오류율 16.4%를 언급한 것이 4차시 도입의 복선이 됩니다.
