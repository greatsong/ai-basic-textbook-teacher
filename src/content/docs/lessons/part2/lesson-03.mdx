## 교사 발화 예시

### 도입 (00-03분)

> "모두가 포기한 분야에서, 한 연구자만 혼자 버텼어요. 동료들은 '신경망은 끝났다'고 했고, 논문을 내도 아무도 안 읽었어요."

> "그런데 이 사람이 발견한 건 놀랍도록 단순한 아이디어였습니다. '이것' 하나를 신경망에 넣자 모든 게 바뀌었어요. 오늘 여러분이 그 아이디어를 직접 발견하게 됩니다."

### 실습1 유도 (03분)

> "2차시에서 XOR이 안 됐죠? 그때 '직선 2개 쓰면 되잖아'라고 했잖아요. 지금 화면에 2층 신경망이 있어요. 은닉 뉴런이 2개니까, 직선 2개를 쓸 수 있을 것 같죠? 한번 해봅시다. '학습 시작'을 누르세요."

(실패 후)

> "안 되죠? 왜일까요? 층을 쌓았는데 왜 안 될까? 화면에 꺼져 있는 스위치가 하나 보이죠? '활성화함수'라고 써있는 거. 그걸 켜보세요."

(성공 후)

> "됐죠? 같은 신경망인데 스위치 하나 켰을 뿐이에요. 대체 이 스위치가 뭐길래?"

### 이론 핵심 멘트 (18-25분)

> "활성화함수 없이 층을 쌓으면, 아무리 쌓아도 결국 직선 하나와 같아요. 곱하기와 더하기를 아무리 반복해도 직선이에요. 10층을 쌓아도, 100층을 쌓아도."

> "활성화함수가 하는 일은 딱 하나예요 — 직선적인 결과를 구부려주는 거예요. 공간을 구부려놓으면 직선으로 나눌 수 없던 패턴도 나눌 수 있게 됩니다."

### 4종 비교 설명 (25-33분)

> "Sigmoid는 AI 초기에 많이 쓰였어요. 부드러운 S자 곡선이라 미분이 가능하거든요. 하지만 양 끝에서 기울기가 거의 0이 돼요. 층이 깊으면 뒤쪽 가중치가 거의 안 바뀌는 문제가 생깁니다. 이걸 '기울기 소실'이라고 해요."

> "ReLU는 놀랍도록 단순해요. 음수면 0, 양수면 그대로. max(0, x). 이 단순한 함수가 딥러닝을 가능하게 만든 핵심 중 하나였습니다."

### 역사 공개 (45분)

> "그 혼자 버텨낸 연구자. 제프리 힌튼. 2024년 노벨 물리학상을 받았어요. 이 사람이 결국 2012년에 세상을 뒤집었어요. 제자와 함께 만든 AlexNet이라는 신경망이, 이미지 인식 대회에서 2위와의 격차를 10% 이상 벌리며 압도적으로 이겼거든요."

> "핵심 비결? 여러분이 방금 켠 그 스위치 — ReLU. 그리고 게임용 그래픽 카드, GPU."

## 시뮬레이터 운영 가이드

### 실습1: 활성화함수 토글 (ActivationToggle)

| 항목 | 내용 |
|------|------|
| **사용 시점** | 실습1 (03-18분) |
| **예상 소요 시간** | OFF 실험 3분 + ON 실험 3분 + 놀라움/토의 4분 + 함수 전환 5분 = 약 15분 |
| **핵심 체험 순서** | (1) OFF 상태에서 학습 시작 → 실패 확인 → (2) ON으로 전환 → 성공 확인 |

**운영 팁:**
- 반드시 OFF 먼저 실패를 경험하게 한 뒤 ON으로 전환하세요. 순서가 바뀌면 놀라움이 사라집니다
- ON으로 전환한 뒤 Sigmoid, ReLU, Tanh를 번갈아 바꿔보게 하세요 — 학습 속도 차이를 관찰하도록 유도
- "왜 같은 구조인데 스위치 하나로 결과가 달라질까?" 질문을 3~5초 열어두세요

### 실습2: 네트워크 빌더 (NetworkBuilder)

| 항목 | 내용 |
|------|------|
| **사용 시점** | 실습2 (33-45분) |
| **예상 소요 시간** | 뉴런 수 변경 5분 + 층 추가 3분 + 파라미터 카운터 관찰 2분 + 토의 2분 = 약 12분 |
| **핵심 체험** | 뉴런을 늘리면 결정 경계가 복잡해지고, 파라미터 수가 급증하는 것을 직접 확인 |

**운영 팁:**
- 은닉 뉴런 2개 → 4개 → 8개 순서로 바꿔가며 학습 결과를 비교하게 하세요
- 은닉층을 1층 → 2층으로 바꾸면 파라미터가 어떻게 변하는지 관찰하게 하세요
- 파라미터 규모 비교 바에서 "지금 17개, GPT-4는 수천억 개" 포인트를 강조하세요
- 연결선의 색상(양수=초록, 음수=빨강)과 두께 변화에 주목하게 하면 가중치 학습을 시각적으로 이해하는 데 도움

| 2 | "활성화함수가 없으면 100층 쌓아도 안 돼요?" | "네, 수학적으로 증명돼요. 선형 함수의 합성은 항상 선형입니다." |
| 3 | "ReLU가 왜 좋아요?" | "첫째, 계산이 극도로 단순해요. max(0, x) 한 줄이에요. 둘째, 양수 영역에서 기울기가 항상 1이라 층이 깊어도 학습 신호가 사라지지 않아요." |
| 4 | "기울기 소실이 뭐예요?" | "Sigmoid의 기울기는 최대 0.25예요. 층이 3개면 0.25 x 0.25 x 0.25 = 0.016. 앞쪽 뉴런은 거의 학습이 안 되는 거예요." |
| 5 | "힌튼은 왜 포기 안 했어요?" | "자기가 옳다고 확신했어요. 군사 연구비도 거부하고 캐나다로 갔습니다. 30년 후 노벨상을 받았죠." |
| 6 | "AlexNet이 뭐예요?" | "2012년 ImageNet 대회에서 이미지 인식 오류율을 16.4%로 낮춘 신경망이에요. 2위가 26.2%였으니 압도적이었죠." |
| 7 | "dying ReLU가 뭐예요?" | "ReLU는 음수 입력이 오면 출력이 0이에요. 만약 가중치가 업데이트돼서 항상 음수만 받게 되면, 그 뉴런은 영원히 0만 출력하게 돼요. 죽은 뉴런이 되는 거죠." |

## 폴백 계획 (기술 장애 시 대안 활동)

### 시나리오 A: 시뮬레이터 전체 장애

**대안 활동 — 활성화함수 손 계산 체험 (25분)**

1. 칠판에 2-1-1 네트워크를 그리고 XOR 데이터를 제시
2. 활성화함수 없이(선형만) 순전파 계산을 학생과 함께 수행 → "결국 직선 하나"를 확인
3. ReLU (max(0, x))를 추가하고 같은 계산을 수행 → 결과가 달라지는 것을 확인
4. 교과서의 "심화: 공간을 구부린다는 것의 수학적 의미" 표를 함께 따라가며 좌표 변환 과정 확인
5. 모눈종이에 변환 전/후 좌표를 직접 찍어보기

### 시나리오 B: 일부 시뮬레이터만 작동

- ActivationToggle만 작동하면 실습1에 집중 (ON/OFF 비교가 핵심)
- NetworkBuilder가 작동하지 않으면 교사 시연 + 구두 설명으로 대체
- 파라미터 카운팅은 칠판에 표로 그려서 비교

## 차시 연결

### 이전 차시 (2차시) 복습 포인트

> "지난 시간에 퍼셉트론으로 AND, OR은 풀었는데 XOR은 안 됐죠. 직선 하나로는 한계가 있었어요. '직선을 여러 개 쓰면 되잖아'라고 했는데, 오늘 그게 생각만큼 간단하지 않다는 걸 발견합니다."

- 2차시의 XOR 좌절 → 3차시의 활성화함수 발견으로 이어지는 내러티브가 핵심
- "직선 2개 쓰면 된다"의 아이디어가 활성화함수 없이는 작동하지 않는다는 것을 체험

### 다음 차시 (4차시) 예고 포인트

> "오늘 활성화함수로 XOR을 풀고, AlexNet이 이미지 인식 대회를 압도한 이야기를 했어요. AlexNet의 오류율이 16.4%라고 했는데 — 이 숫자는 대체 어떻게 계산한 걸까요? '더 낫다'는 걸 어떻게 숫자로 표현할까요? 다음 시간에 그 이야기를 합니다."

**교사 메모:** 3차시의 "스위치 하나로 불가능이 가능으로" 경험은 학생들에게 강한 인상을 남깁니다. 이 경험을 4차시의 "틀린 정도를 숫자로 재는 법"과 연결할 때, "활성화함수를 켜면 오류가 줄어든다 → 그 '오류'를 정확히 어떻게 측정하는가?"로 자연스럽게 이어주세요.
