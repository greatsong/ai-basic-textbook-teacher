## 지도서 구성

이 교사용 지도서는 10차시 인공지능 기초 수업의 원활한 진행을 돕기 위해 제작되었습니다. 학생용 교과서와 1:1로 대응하며, 각 차시별로 교사가 필요로 하는 모든 정보를 한곳에 모았습니다.

---

## 각 차시별 지도서에 포함된 내용

모든 차시 지도서는 동일한 구조를 따릅니다. 처음 몇 차시만 익히면 나머지도 같은 흐름으로 읽을 수 있습니다.

| 섹션 | 내용 | 활용법 |
|------|------|--------|
| **수업 개요** | 차시, 단원, 주제, 학습 목표, 핵심 질문, 평가 연결 | 수업 전 1분 훑어보기 |
| **수업 준비물** | 필수/선택 준비물, 사전 점검 사항 | 수업 3일 전 확인 |
| **수업 흐름** | 분 단위 시간 배분, 활동, 교사 역할, 핵심 포인트 | 수업의 뼈대. 시간 관리의 핵심 |
| **교사 발화 예시** | 도입, 전개, 정리 단계별 교사 멘트 | 그대로 사용하거나 스타일에 맞게 수정 |
| **시뮬레이터 운영 가이드** | 각 시뮬레이터의 사용 시점, 소요 시간, 조작법, 운영 팁 | 시뮬레이터 사전 체험 시 참고 |
| **학생 예상 질문 & 답변** | 학생이 자주 묻는 질문과 교사 대응 방법 | 수업 전 한 번 읽어두면 즉각 대응 가능 |
| **평가 포인트** | 관찰 기준, 수준별 판단 기준 | 수업 중 관찰 및 평가 시 참고 |
| **폴백 계획** | 기술 장애 시 대안 활동 | 만약의 사태에 대비 |
| **차시 연결** | 이전/다음 차시와의 연결 포인트 | 도입부 복습, 마무리 예고에 활용 |
| **교사 배경지식** | 교사가 알아두면 좋은 심화 정보 | 학생 질문 대응 및 자신감 확보 |
| **수준별 지도 방안** | 빠른/느린 학생 대응 전략 | 개별화 수업에 활용 |
| **흔한 오개념** | 학생들이 자주 가지는 잘못된 이해 | 수업 중 오개념 교정에 활용 |
| **참고자료** | 영상, 논문, 웹사이트 링크 | 교사 자기 학습 또는 학생 보충 자료 |

## 활용 시나리오별 가이드

### 시나리오 1: 처음으로 이 수업을 진행하는 교사

1. **수업 전 준비** 페이지를 먼저 읽고 전체 환경을 세팅하세요.
2. 해당 차시 지도서를 **전체 통독**하세요 (15~20분).
3. **교사 발화 예시**를 소리 내어 읽어보면 수업 리허설이 됩니다.
4. **시뮬레이터를 직접 조작**해보세요 (10~15분).
5. **학생 예상 질문**을 한 번 읽어두면, 당황하지 않고 대응할 수 있습니다.
6. **폴백 계획**을 확인하고, 필요한 인쇄물이 있으면 미리 준비하세요.

### 시나리오 2: 경험이 있는 교사 (2회 이상 진행)

1. **수업 흐름 표**만 빠르게 확인하여 시간 배분을 환기합니다.
2. 이전에 학생들이 어려워했던 부분의 **교사 발화 예시**를 다시 읽습니다.
3. 이번 학급의 특성에 맞게 **수준별 지도 방안**을 조정합니다.

### 시나리오 3: 수업 중 참고가 필요할 때

1. **학생 예상 질문 표**를 태블릿이나 노트북에 띄워두세요.
2. 예상치 못한 질문이 나오면 "좋은 질문이에요, 다음에 자세히 다루겠습니다"로 넘기고, 쉬는 시간에 지도서를 확인하세요.
3. 시뮬레이터에 문제가 생기면 즉시 **폴백 계획** 섹션을 참고하세요.

## 교사 멘트 활용법

### 그대로 사용해도 됩니다

교사 발화 예시는 **그대로 읽어도 자연스럽도록** 작성되어 있습니다. 처음 수업하는 경우, 수정 없이 그대로 사용하는 것을 권장합니다.

### 자기 스타일로 수정해도 됩니다

멘트의 **핵심 포인트**(굵은 글씨, 인용 박스)만 유지하면, 나머지는 자유롭게 바꿔도 됩니다. 예를 들어:

- 지도서: "안개 낀 산꼭대기에 서 있다고 상상해보세요."
- 수정: "여러분이 눈을 가리고 언덕을 내려가야 한다고 생각해보세요."

핵심 비유의 **방향**이 같으면 표현은 자유입니다.

### 침묵 타이밍은 지켜주세요

멘트 사이의 **(3~5초 침묵)** 같은 지시는 매우 중요합니다. 학생에게 생각할 시간을 주는 것이 이 수업의 핵심 설계입니다. 침묵이 어색하더라도, 최소 2~3초는 기다려주세요.

## 수업 전체의 핵심 설계 원칙

이 수업을 이해하고 진행하는 데 가장 중요한 설계 원칙 5가지입니다.

### 1. 체험 → 이론 → 역사 (Experience First)

모든 차시는 **"먼저 체험하고, 그 다음 이론으로 설명하고, 마지막에 역사적 맥락을 공개하는"** 순서를 따릅니다. 이론을 먼저 설명하고 실습하는 전통적 방식과 정반대입니다.

- 2차시: XOR을 먼저 시도 → 안 되는 이유를 이론으로 설명 → 민스키·파퍼트 이야기
- 3차시: 활성화함수 OFF로 먼저 실패 → ON으로 성공 → 왜 되는지 이론 → 힌튼 이야기

**왜 이렇게 설계했는가:** 체험이 먼저 와야 이론에 대한 필요성을 학생이 스스로 느낍니다. "이걸 왜 배워야 해요?"라는 질문이 사라집니다.

### 2. 좌절이 학습의 핵심 동력

2차시의 XOR 좌절, 3차시의 활성화함수 OFF 실패, 5차시의 1차 직감 도전 실패 — 이 **의도된 좌절**이 다음 단계의 동기 부여가 됩니다.

:::caution[절대 하지 말아야 할 것]
좌절을 건너뛰지 마세요. "시간이 부족하니까 바로 정답을 알려줄게요"라고 하면, 이후 설명의 임팩트가 크게 줄어듭니다. 학생이 최소 2~3분은 직접 시도하고 실패하는 시간을 반드시 확보하세요.
:::

### 3. 열린 질문은 닫지 않는다

1차시의 "기계가 생각할 수 있는가?"는 수업 전체를 관통하는 질문입니다. **어느 차시에서도 이 질문에 "정답"을 주지 마세요.** 학생이 자신만의 답을 형성해가는 과정이 이 수업의 가장 큰 가치입니다.

### 4. 원리는 같고 규모만 다르다

2차시 퍼셉트론(파라미터 3개)과 GPT-4(파라미터 수천억 개)는 **같은 원리**(가중합 → 활성화 → 손실 최소화)로 작동합니다. 이 메시지를 수업 전체에 걸쳐 반복하세요. 학생이 "AI는 마법이 아니라 수학이구나"라고 느끼면 성공입니다.

### 5. 차시 간 연결 고리가 생명

각 차시의 마무리에 다음 차시 예고가 있고, 각 차시의 도입에 이전 차시 복습이 있습니다. 이 **연결 고리**를 건너뛰지 마세요. 학생이 "아, 지난 시간에 그래서 그랬구나!"라고 느끼는 순간이 깊은 학습의 증거입니다.

## 시간 관리 팁

### 시간이 부족할 때

1. **역사 공개**를 간략하게 줄이세요 (2분 → 1분). 핵심 한 문장만 전달.
2. **실습 라운드 수**를 줄이세요 (4차시 3라운드 → 2라운드).
3. **학생 예상 질문 대응**은 수업 후 개별 안내로 미루세요.
4. 절대 줄이면 안 되는 것: **실습 체험 시간**, **좌절 체험 시간**, **침묵 대기 시간**

### 시간이 남을 때

1. **학생 발표/공유** 시간을 늘리세요 (가장 효과적).
2. 시뮬레이터 **자유 탐험** 시간을 추가하세요.
3. 교사 발화 예시의 **보충 설명**을 추가하세요.
4. **심화 질문**을 던지세요 (학생 예상 질문 표의 마지막 항목들이 심화 질문).
