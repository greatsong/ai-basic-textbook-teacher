## 지도서 구성

이 교사용 지도서는 10차시 인공지능 기초 수업의 원활한 진행을 돕기 위해 제작되었습니다.

### 각 차시별 지도서에 포함된 내용

- **수업 흐름**: 도입-전개-정리 단계별 시간 배분과 활동 안내
- **교사 멘트**: 주요 설명 시 활용할 수 있는 예시 멘트
- **학생 예상 반응**: 학생들이 자주 하는 질문과 대응 방법
- **트러블슈팅**: 시뮬레이터·활동 진행 시 발생할 수 있는 문제와 해결 방법

### 활용 팁

1. 수업 전에 해당 차시의 지도서를 한 번 통독하세요.
2. 학생용 교과서의 활동을 직접 체험해 보세요.
3. 교사 멘트는 그대로 사용하거나, 본인의 스타일에 맞게 수정하여 사용하세요.
