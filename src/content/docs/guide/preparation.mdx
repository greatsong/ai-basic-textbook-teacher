## 수업 환경 확인

10차시 인공지능 기초 수업을 시작하기 전에 아래 항목을 확인하세요.

### 기기 및 네트워크

- 학생 1인당 태블릿 또는 노트북 1대
- 안정적인 인터넷 연결 (시뮬레이터 사용에 필요)
- 최신 버전의 웹 브라우저 (Chrome, Edge 권장)

### 교실 환경

- 대형 디스플레이 또는 프로젝터 (교사 시연용)
- 모둠 활동을 위한 좌석 배치 (4인 1모둠 권장)

### 준비물

- 각 차시별 활동지 인쇄물 (필요 시)
- 학생용 디지털 교과서 접속 URL 안내

:::note
상세 준비물은 각 차시별 지도서에서 별도 안내합니다.
:::
