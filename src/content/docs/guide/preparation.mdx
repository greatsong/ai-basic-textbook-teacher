## 수업 환경 확인

10차시 인공지능 기초 수업을 시작하기 전에 아래 항목을 꼼꼼히 확인하세요.

### 기기 및 네트워크

| 항목 | 최소 사양 | 권장 사양 | 비고 |
|------|----------|----------|------|
| 학생 기기 | 태블릿 또는 노트북 1인 1대 | 크롬북 이상, 13인치 이상 화면 | 시뮬레이터가 작은 화면에서 UI가 잘릴 수 있음 |
| 인터넷 | 10Mbps 이상 | 50Mbps 이상 | 30명 동시 접속 기준. 1차시 튜링 테스트는 소켓 통신 사용 |
| 브라우저 | Chrome 90+, Edge 90+ | 최신 Chrome | Safari에서 일부 시뮬레이터 호환 문제 가능 |
| 교사 PC | 프로젝터 연결 가능 | 듀얼 모니터 (시연+지도서 동시 보기) | |

:::caution[사전 테스트 필수]
수업 1주 전에 컴퓨터실에서 실제로 시뮬레이터를 열어보세요. 학교 네트워크 방화벽이 웹소켓(1차시)이나 AI API(10차시)를 차단하는 경우가 있습니다. IT 담당 교사에게 미리 화이트리스트 요청이 필요할 수 있습니다.
:::

### 교실 환경

| 항목 | 설명 |
|------|------|
| 디스플레이 | 대형 TV 또는 프로젝터 (교사 시연, 슬라이드, 학생 결과 공유용) |
| 좌석 배치 | **4인 1모둠** 권장 (9차시 팀 활동, 10차시 모둠 토의에 필수) |
| 칠판/화이트보드 | 6차시 네트워크 구조 판서, 7차시 벡터 연산 판서에 사용 |
| 타이머 | 4차시 30초 대결, 5차시 레이싱 시간 관리 (스마트폰 앱 가능) |

### 모둠 편성 가이드

모둠은 **수업 전체에 걸쳐 동일하게** 유지하는 것을 권장합니다.

- **4인 1모둠** 기본 (5~6차시 팀 레이싱, 9~10차시 팀 활동에 최적)
- 수학/논리에 강한 학생과 그렇지 않은 학생을 **골고루 배치**
- AI에 대한 사전 경험이 다양하도록 섞기 (ChatGPT 파워 유저 + 처음 접하는 학생)

## 차시별 준비물 총정리

### 전 차시 공통 준비물

- 학생용 디지털 교과서 접속 URL (칠판/LMS에 상시 게시)
- 교사용 지도서 (이 사이트) 해당 차시 탭 열어두기
- 프로젝터/대형 디스플레이 연결 확인

### 차시별 특수 준비물

| 차시 | 필수 준비물 | 선택 준비물 | 사전 작업 |
|------|-----------|-----------|----------|
| 1차시 | 차오차오 모드 웹앱, 구글 설문 | 타이머 앱 | 웹앱 서버 확인, 설문 3문항 세팅, 매칭 테스트 |
| 2차시 | 퍼셉트론 시뮬레이터 2종 | 모눈종이, 그래프용지 | 시뮬레이터 AND/OR/XOR 모드 전환 확인 |
| 3차시 | 시뮬레이터 3종 (토글, 비교, 빌더) | 4종 비교표 프린트 | 3종 시뮬레이터 동작 확인 |
| 4차시 | 직선 피팅, 손실 등고선 시뮬레이터 | MSE 워크시트, 계산기 | 3라운드 모드 확인, 힌트 버튼 확인 |
| 5차시 | 3D 레이싱, 학습률 비교, 로컬 미니마 시뮬레이터 | 팀 편성표, 순위 기록판 | 팀 편성 결정, initial/strategic 모드 확인 |
| 6차시 | 순전파 계산기, 역전파 애니메이션, 역전파 ON/OFF, 반복 훈련기 | 칠판+마커, 학습지 | 계산기 또는 스마트폰 계산기 안내 |
| 7차시 | 토크나이저, 벡터 연산기, 임베딩 갤럭시 | 포스트잇, 칠판 | 멀티플레이어 접속 테스트 |
| 8차시 | 다음 단어 예측기, 어텐션 시각화기 | A4 용지, 칠판 | Temperature 슬라이더 작동 확인 |
| 9차시 | 교과서 7편 논문 카드, 실시간 퀴즈 | 타이머, 칠판 | 팀 워크시트 인쇄, 퀴즈 문항 확인 |
| 10차시 | AI 한계 실험, before/after 비교기, 셀프 체크 퀴즈 | 토의 워크시트, 칠판 | **1차시 설문 결과 요약 준비**, 서술형 문항지 인쇄 |

:::tip[10차시를 위한 1차시 준비]
1차시 구글 설문 결과를 반드시 저장해두세요. 10차시의 before/after 비교에 필수적입니다. 설문 결과를 프로젝터로 보여줄 수 있도록 요약본을 미리 만들어두면 좋습니다.
:::

## 교사 사전 학습 가이드

### 반드시 읽어야 할 배경지식

이 수업을 진행하기 위해 교사가 미리 알아두어야 할 최소한의 배경지식입니다. **수업에서 모든 것을 설명할 필요는 없지만**, 학생 질문에 대응하려면 아래 수준의 이해가 필요합니다.

| 주제 | 교사가 알아야 할 수준 | 추천 자료 |
|------|---------------------|----------|
| 튜링 테스트 | 모방 게임의 구조, 의미, 한계 | Turing (1950) Section 1 (2~3페이지만) |
| 중국어 방 | 사고실험의 핵심 논점, 주요 반론(시스템 반론) | Stanford Encyclopedia "Chinese Room" |
| 퍼셉트론 | 입력-가중치-편향-활성화 구조, AND/OR/XOR | 교과서 2차시 내용으로 충분 |
| 활성화함수 | 비선형성이 왜 필요한지, 4종의 차이 | 교과서 3차시 + 3Blue1Brown 영상 |
| MSE | 공식, 제곱하는 이유, 이상치 효과 | 교과서 4차시 내용으로 충분 |
| 경사하강법 | 업데이트 규칙, 학습률, 로컬 미니마 | 교과서 5차시 + 3Blue1Brown "Gradient Descent" |
| 역전파 | 연쇄법칙의 직관적 이해, 순전파→역전파 흐름 | 교과서 6차시 + 3Blue1Brown "Backpropagation" |
| 토큰화/임베딩 | BPE의 기본 원리, 워드 벡터 개념 | 교과서 7차시 + Jay Alammar의 "Word2Vec" 포스트 |
| 트랜스포머 | 어텐션의 직관적 의미, RNN과의 차이 | 교과서 8차시 + Jay Alammar의 "The Illustrated Transformer" |
| AI 역사 | 7편 논문의 핵심 기여 | 교과서 9차시 카드 7장 |

### 추천 영상 자료 (교사 자기 학습용)

| 영상 | 시간 | 관련 차시 | 내용 |
|------|------|----------|------|
| 3Blue1Brown "Neural Networks" 시리즈 (Ch. 1~4) | 각 15~20분 | 2~6차시 | 퍼셉트론부터 역전파까지 시각적 설명 |
| TED-Ed "The Turing Test" | 4분 30초 | 1차시 | 튜링 테스트의 핵심을 4분에 요약 |
| Computerphile "Chinese Room Argument" | 10분 | 1차시 | 중국어 방 논증의 깊이 있는 설명 |
| StatQuest "Gradient Descent" | 10분 | 5차시 | 경사하강법의 직관적 설명 |

### 교사가 직접 체험해봐야 할 것

:::tip[수업 전 반드시 해보세요]
1. **학생용 교과서의 모든 시뮬레이터를 직접 조작**해보세요 (최소 1시간)
2. **차오차오 모드 튜링 테스트**를 동료 교사와 함께 테스트해보세요
3. **MSE 손계산**을 직접 해보세요 (4차시 예제)
4. **순전파 계산**을 직접 해보세요 (6차시 예제)
5. ChatGPT 또는 Claude에게 **환각 유도 질문**을 해보세요 (10차시 실험 예행)
:::

## 기술 환경 체크리스트

수업 1주 전, 3일 전, 당일에 각각 확인하세요.

### 1주 전 체크리스트

- [ ] 컴퓨터실 예약 확인 (10주 연속)
- [ ] 학생용 교과서 URL 접속 테스트
- [ ] 시뮬레이터 전체 작동 확인
- [ ] 학교 네트워크에서 웹소켓 통신 가능 여부 확인 (1차시용)
- [ ] 구글 설문 생성 (1차시용, 3개 질문)
- [ ] 모둠 편성 완료

### 3일 전 체크리스트

- [ ] 해당 차시 지도서 통독
- [ ] 해당 차시 시뮬레이터 직접 체험
- [ ] 필요한 인쇄물 준비 (워크시트, 폴백 자료 등)
- [ ] 폴백 계획 준비물 확인 (만약의 기술 장애 대비)

### 수업 당일 체크리스트 (수업 10분 전)

- [ ] 프로젝터/디스플레이 연결 확인
- [ ] 교사 PC에서 시뮬레이터 정상 작동 확인
- [ ] 학생 PC 2~3대에서 접속 테스트
- [ ] 타이머 앱 준비 (4, 5차시)
- [ ] 칠판에 교과서 URL, 설문 URL 게시

5주로 압축할 경우, 각 주에 2차시씩 진행합니다. 연속 수업의 장점은 차시 간 연결이 강해진다는 것입니다.

## 학생 사전 안내 사항

첫 수업 전에 학생들에게 안내할 사항입니다.

1. **디지털 교과서**: 교과서는 웹사이트로 제공됩니다. 별도 교재 구매 불필요.
2. **시뮬레이터**: 매 차시 인터랙티브 시뮬레이터를 사용합니다. 크롬 브라우저를 권장합니다.
3. **모둠 활동**: 4인 1모둠으로 활동합니다. 모둠은 10주간 유지됩니다.
4. **평가**: 수업 참여(40%) + 서술형 평가(60%). 서술형 문항은 사전 공개됩니다.
5. **1차시 설문**: 1차시에 작성한 설문을 10차시에 다시 보게 됩니다. 솔직하게 작성해주세요.
