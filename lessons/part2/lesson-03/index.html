수업 준비물

섹션 제목: “수업 준비물”
구분항목비고
필수컴퓨터실 (학생 1인 1PC)시뮬레이터 웹앱 3종 사용
필수프로젝터 / 대형 디스플레이활성화함수 ON/OFF 비교 시연용
필수활성화함수 토글 시뮬레이터 (ActivationToggle)OFF → ON 체험
필수활성화함수 비교 시뮬레이터 (ActivationComparison)4종 비교
필수네트워크 빌더 시뮬레이터 (NetworkBuilder)뉴런/층 추가 체험
선택활성화함수 4종 비교표 프린트칠판 게시 or 학생 배부

사전 점검 사항:

  • 3종 시뮬레이터 정상 작동 확인 (ActivationToggle, ActivationComparison, NetworkBuilder)
  • ActivationToggle에서 OFF → ON 전환 시 XOR 학습 성공 여부 확인
  • NetworkBuilder에서 뉴런/층 수 변경 및 파라미터 카운터 작동 확인
  • 2차시 XOR 결과를 학생이 기억하고 있는지 확인할 질문 준비

배경 지식: 교사가 알아두면 좋은 것

섹션 제목: “배경 지식: 교사가 알아두면 좋은 것”

왜 활성화함수 없이 층을 쌓으면 안 되는가

  • 선형 함수의 합성은 항상 선형: y = w₂(w₁x + b₁) + b₂ = (w₂w₁)x + (w₂b₁ + b₂) → 직선 하나
  • 10층을 쌓아도, 100층을 쌓아도 곱하기와 더하기의 반복이면 결과는 항상 직선
  • 활성화함수가 하는 일: 각 층의 결과를 비선형적으로 변환 → 층을 쌓는 의미가 생김
  • 비유: 종이를 접으면 직선으로 나눌 수 없던 패턴이 나눠진다 (공간을 구부리는 것)

활성화함수 4종 비교

함수수식출력 범위핵심 특징등장 시기
계단 함수(Step)0 or 11미분 불가능 → 다층 학습 불가1958 (로젠블랫)
Sigmoid1/(1+e^(-x))(0, 1)미분 가능! 하지만 기울기 최대 0.251986 (역전파에 적용)
Tanh(e^x - e^(-x))/(e^x + e^(-x))(-1, 1)음수 표현 가능, 여전히 기울기 소실1990년대
ReLUmax(0, x)[0, +inf)계산 극도로 단순, 기울기 소실 없음2012 (AlexNet)

기울기 소실 문제 (Vanishing Gradient)

  • Sigmoid의 미분값(기울기) 최대 0.25
  • 역전파는 이 기울기를 층마다 곱해서 전달
  • 3층: 0.25 x 0.25 x 0.25 = 0.016 → 앞쪽 가중치는 거의 학습 안 됨
  • 5층: 0.25^5 = 0.00098 → 사실상 학습 불가능
  • ReLU는 양수 영역에서 기울기가 항상 1 → 기울기 소실 없음 → “딥”러닝 가능

dying ReLU 문제

  • ReLU는 음수 입력이면 출력 0, 기울기도 0
  • 가중치가 업데이트되어 항상 음수만 받게 되면 → 영원히 0만 출력 → “죽은 뉴런”
  • 해결책: Leaky ReLU (음수 영역에서 아주 작은 기울기), GELU 등
  • 학생에게는 “이런 문제도 있다” 정도로만 언급

제프리 힌튼 (Geoffrey Hinton, 1947-)

  • 영국 출신, “딥러닝의 아버지”
  • 고조부: 조지 부울 — AND, OR, NOT의 수학적 토대(부울 대수)를 만든 사람
  • 외가 쪽: 조지 에버리스트 — 에베레스트산의 이름이 된 측량사
  • 1970-80년대: “신경망은 끝났다”는 학계 분위기 속에서 혼자 연구 지속
  • 군사 연구비(DARPA) 거부 → 캐나다 토론토 대학으로 이주
  • 1986년: 럼멜하트, 윌리엄스와 함께 역전파 논문 발표 (Nature)
  • 2006년: 딥 빌리프 네트워크 → “딥러닝”이라는 이름의 시작
  • 2012년: 제자들과 AlexNet 개발 → 이미지 인식 대회 압도
  • 2024년: 노벨 물리학상 수상

AlexNet (2012)

  • 힌튼의 제자 알렉스 크리제프스키와 일리아 수츠케버(이후 OpenAI 공동 창립자)가 제작
  • ImageNet 대회 오류율 16.4% (2위 26.2%와 10%포인트 차이)
  • 핵심 비결: ReLU 활성화함수 + GPU(게임용 그래픽카드 GTX 580 2장)
  • 이 이후 컴퓨터 비전 분야가 전부 딥러닝으로 전환

학생에게 어느 정도까지 말할 것인가:

  • 힌튼이 혼자 버텨낸 것, 노벨상을 받은 것 → 반드시 말하기
  • 부울과의 가계 연결 → 관심 있는 학생에게 (2차시 AND/OR과 연결)
  • 수츠케버가 OpenAI 공동 창립자라는 것 → “여러분이 쓰는 ChatGPT의 핵심 인물”
  • GPU 이야기 → “게임용 그래픽카드로 AI를 만들었다” (학생 관심 유도)

정답: ②

해설: 활성화함수 없이 곱하기와 더하기만 반복하면, 결과는 항상 직선(일차함수)입니다. y = w₁x + b₁을 2층에 넣으면 z = w₂(w₁x + b₁) + b₂ = (w₂w₁)x + (w₂b₁ + b₂) → 직선 하나. 10층, 100층도 마찬가지입니다.

  2. GPU — 게이머용 NVIDIA 그래픽 카드 2장의 병렬 연산 능력을 신경망 학습에 활용했습니다.
  3. 대규모 데이터(ImageNet) — 120만 장의 학습 이미지가 깊은 신경망의 파라미터를 충분히 학습시킬 수 있었습니다.

이 중 가장 근본적인 요인은 ReLU입니다. GPU와 데이터는 “더 많이, 더 빠르게”의 문제이지만, ReLU는 “가능 vs 불가능”의 문제였기 때문입니다. 시그모이드로는 기울기가 소실되어 깊은 신경망의 학습 자체가 불가능했으므로, 알고리즘(ReLU)이 바뀌었기 때문에 하드웨어(GPU)와 데이터(ImageNet)가 비로소 의미를 가질 수 있었습니다.

채점 기준 (루브릭):

수준기준배점
상(5점)3가지 요인을 정확히 서술하고, ReLU가 가장 근본적인 이유를 “가능/불가능”의 관점에서 논리적으로 설명함5
중(3점)3가지 요인을 나열했으나, 가장 근본적인 요인에 대한 설명이 부족하거나 부정확함3
하(1점)1~2가지 요인만 나열하거나, 요인 간 관계를 설명하지 못함1

문제 6. 기울기 소실 계산 (계산형)

섹션 제목: “문제 6. 기울기 소실 계산 (계산형)”

예시 답안:

  1. 3층: 0.25 × 0.25 × 0.25 = 0.016 (약 1.6%)
  2. 5층: 0.25 × 0.25 × 0.25 × 0.25 × 0.25 = 0.00098 (약 0.1%)
  3. 기울기가 이렇게 작아지면, 앞쪽 뉴런의 가중치는 거의 업데이트되지 않아 사실상 학습이 불가능해집니다. 이것이 기울기 소실 문제입니다. ReLU는 양수 영역에서 기울기가 항상 1이므로, 층이 깊어져도 기울기가 사라지지 않아 이 문제를 해결합니다.

채점 기준 (루브릭):

수준기준배점
상(5점)3층, 5층 계산이 모두 정확하고, 기울기 소실이 문제가 되는 이유와 ReLU의 해결 방식을 설명함5
중(3점)계산은 맞지만 기울기 소실의 의미 설명이 부족하거나, ReLU 해결 방식 설명이 빠짐3
하(1점)계산을 시도했으나 오류가 있거나, 기울기 소실의 의미를 전혀 설명하지 못함1

문제 7. 직선 합성 계산 (계산형)

섹션 제목: “문제 7. 직선 합성 계산 (계산형)”

예시 답안:

  1. z = 2y + 3 = 2(4x + 2) + 3 = 8x + 4 + 3 = 8x + 7
  2. z = 8x + 7은 x에 대한 일차함수(직선)입니다. (기울기 8, 절편 7)
  3. 1층(4x + 2)과 2층(2y + 3)을 거쳤지만, 결과는 8x + 7이라는 직선 하나와 동일합니다. 곱하기와 더하기만 반복하면 결과가 항상 직선이므로, 활성화함수 없이 층을 쌓는 것은 의미가 없습니다. 활성화함수가 있어야 층을 쌓는 의미가 생깁니다.

채점 기준 (루브릭):

수준기준배점
상(5점)대입 계산이 정확하고, 결과가 직선임을 확인하며, 활성화함수 필요성까지 논리적으로 연결함5
중(3점)대입 계산은 맞지만 직선임을 확인하는 과정이 부족하거나, 활성화함수와의 연결이 약함3
하(1점)대입 계산에 오류가 있거나, 문제의 의미를 파악하지 못함1
