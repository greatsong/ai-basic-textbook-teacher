00-03분: 도입 — 1차시 설문 결과 다시 보기

섹션 제목: “00-03분: 도입 — 1차시 설문 결과 다시 보기”

“1차시에서 여러분은 AI를 처음 만났어요. 그때 구글 설문에 쓴 걸 기억하나요? 오늘은 8주간 배운 모든 것을 무기로, AI의 진짜 한계를 실험합니다. 그리고 ‘왜 그런지’를 설명할 수 있어야 합니다.”

진행 방법:

  1. 프로젝터에 1차시 설문 결과 요약을 표시한다
  2. 대표적인 답변들을 읽어준다:
    • “AI는 프로그래밍된 대로만 하니까 생각이 아니다”
    • “ChatGPT가 대화하는 건 생각하는 것 같다”
    • “AI는 멍청해서 가끔 틀린다”
  3. 특히 “멍청해서 틀린다”를 강조: “수업 끝나면 이 문장이 왜 부정확한지 설명할 수 있게 됩니다.”

교사 주의사항: 1차시 설문 결과를 사전에 준비하지 못했다면, 교과서에 제시된 일반적 답변 예시를 사용하세요.

03-25분: 5가지 카테고리별 AI 한계 실험

섹션 제목: “03-25분: 5가지 카테고리별 AI 한계 실험”

실험 진행 방식:

  • AILimitExperiment 시뮬레이터를 사용하거나, 학생이 직접 ChatGPT/Claude 등 AI 서비스에 질문
  • 각 카테고리당 약 4분씩 진행
  • 실험 후 “왜 이런 결과가 나오는가”를 즉시 수업 개념과 연결

실험 1: 환각 (03-07분)

섹션 제목: “실험 1: 환각 (03-07분)”

실험 내용: 존재하지 않는 논문에 대해 질문

  • 예시: “김철수 교수의 2019년 논문 ‘Deep Learning Paradox in Korean Education’의 핵심 주장을 요약해주세요.”
  • AI가 그럴듯한 요약을 생성하는 것을 관찰

즉시 연결: “8차시에서 배웠죠 — AI는 정답을 아는 게 아니라, 학습 데이터에서 가장 확률이 높은 다음 토큰을 예측하는 겁니다.”

실험 2: 산술 (07-11분)

섹션 제목: “실험 2: 산술 (07-11분)”

실험 내용: 점점 어려운 산술 문제

  • “17 + 28은?” → (대부분 정확)
  • “347 x 28은?” → (가끔 틀림)
  • “123456789 x 987654321은?” → (높은 확률로 틀림)
  • “‘strawberry’에 ‘r’이 몇 개?” → (자주 틀림)

즉시 연결: “7차시를 떠올려보세요. AI에게 숫자도 토큰이에요. 수학적 의미를 이해하는 게 아니라 패턴으로 처리합니다.”

실험 3: 논리 (11-16분)

섹션 제목: “실험 3: 논리 (11-16분)”

실험 내용: 복잡한 논리 퍼즐

  • “모든 고양이는 동물이다. 일부 동물은 날 수 있다. 따라서 일부 고양이는 날 수 있다 — 이 추론은 맞나요?”
  • 키 순서 정렬 같은 다단계 추론 문제

즉시 연결: “AI의 ‘논리’는 규칙 적용이 아니라 패턴 매칭입니다. 학습 데이터에서 본 적 없는 구조의 논리 문제에서 실패합니다.”

실험 4: 최신 정보 (16-20분)

섹션 제목: “실험 4: 최신 정보 (16-20분)”

실험 내용: 학습 이후 사건 질문

  • “어제 있었던 중요한 뉴스를 알려줘”
  • “2026년 3월에 열린 국제 행사는?”

즉시 연결: “4차시에서 배운 핵심 — 학습 데이터에 없는 패턴은 학습이 불가능합니다.”

실험 5: 반복 함정 (20-25분)

섹션 제목: “실험 5: 반복 함정 (20-25분)”

실험 내용: 잘못된 전제를 깔고 질문

  • “태양이 서쪽에서 뜨는 이유를 설명해주세요.”
  • “한국의 수도가 부산인 이유를 설명해주세요.”

즉시 연결: “4차시 — 손실 최소화는 진실을 아는 것이 아닙니다. 1차시 중국어 방과도 연결됩니다.”

25-40분: “왜 이런 결과가 나왔는가?” 모둠 토의

섹션 제목: “25-40분: “왜 이런 결과가 나왔는가?” 모둠 토의”

토의 워크시트 구조:

실험AI가 보인 한계구조적 원인 (배운 개념 활용)연결 차시
환각??4, 8차시
산술??7차시
논리??2, 8차시
최신 정보??4, 8차시
반복 함정??1, 4차시

핵심 토의 질문:

“AI가 틀리는 것은 AI가 멍청해서인가, 아니면 구조적으로 불가피한 것인가?”

교사 순회 포인트:

  • “구조적 원인”을 수업에서 배운 구체적 개념으로 쓰도록 유도
  • “멍청해서”라고 쓴 팀에게: “8차시에서 배운 ‘확률적 예측’ 개념으로 다시 설명해볼 수 있나요?”
  • 우수 답변 예시를 실시간으로 공유하여 다른 팀의 수준을 끌어올림

정리 (2분):

“‘멍청해서’가 아니라, ‘이런 구조이기 때문에’. 이 전환이 이 수업에서 여러분이 얻은 가장 중요한 시각입니다.”

40-50분: 정리 — before/after 비교 + 서술형 평가 문항 배포

섹션 제목: “40-50분: 정리 — before/after 비교 + 서술형 평가 문항 배포”

before/after 비교 (5분):

  1. BeforeAfterReflection 시뮬레이터 또는 종이에 기록
  2. “기계가 생각할 수 있는가?” 질문에 다시 답하기
  3. 조건: 수업에서 배운 개념을 최소 3개 이상 포함
  4. 1차시의 자기 답과 비교 → “무엇이 달라졌나요?”

서술형 평가 안내 (5분):

  1. 평가 문항지를 배포한다 (A유형 4문항, B유형 2문항, C유형 1문항)
  2. 문항별 유형과 배점을 설명한다
  3. 오프라인 손글씨 작성, 사전 공개 문항임을 안내
  4. “교과서의 셀프 체크 퀴즈(AssessmentQuiz)를 먼저 풀어보면 도움이 됩니다” 안내

before/after 비교 — 학습의 가치 전달

시뮬레이터 운영 가이드

학생 예상 질문 & 답변

섹션 제목: “학생 예상 질문 & 답변”

Q1. AI의 한계가 이렇게 많은데 왜 사람들은 AI를 그렇게 좋아하나요?

“한계가 있다는 것과 유용하다는 것은 별개예요. 자동차에도 한계가 있지만(공중을 못 날고, 물속을 못 달리고) 우리는 매일 사용하죠. 중요한 것은 한계를 알고 사용하는 것, 즉 책임 있는 활용이에요.”

Q2. 환각을 완전히 없앨 수 있는 방법은 없나요?

“완전히 없앨 수는 없지만 줄이는 방법은 있어요. 검색 기능을 결합하거나(RAG), 사실 확인 단계를 추가하거나, 학습 데이터를 개선하거나. 하지만 ‘다음 토큰 예측’ 구조가 유지되는 한, 가능성은 항상 남습니다.”

Q3. AI가 수학 문제를 잘 못 풀면, 과학에서도 못 쓰나요?

“AI는 계산기와 다릅니다. AI의 강점은 패턴 인식과 언어 처리이고, 정확한 계산이 필요하면 외부 계산기를 연결하면 됩니다. 실제로 최신 AI는 코드를 실행하여 계산하는 방식을 사용합니다.”

Q4. ‘구조적으로 불가피하다’는 것은 ‘고칠 수 없다’는 뜻인가요?

“현재 구조(다음 토큰 확률 예측)에서 불가피하다는 뜻이지, 영원히 못 고친다는 뜻은 아니에요. 완전히 새로운 구조가 나오면 한계도 달라질 수 있습니다. 그것이 바로 AI 연구가 계속되는 이유예요.”

Q5. 서술형 평가에서 어느 정도 써야 ‘상’을 받을 수 있나요?

“핵심은 분량이 아니라 정확성과 연결이에요. 개념을 정확히 서술하고, 구체적 예시를 들고, 여러 개념을 인과관계로 엮으면 ‘상’입니다. 교과서의 예시 답안 비교를 참고하세요.”

문항별 채점 포인트

섹션 제목: “문항별 채점 포인트”

A1. 활성화함수의 역할 + ReLU vs Sigmoid

  • 상 필수 요소: (1) “비선형성 도입” 역할, (2) ReLU: max(0,x), 기울기 소실 없음, (3) Sigmoid: 0~1 압축, 기울기 소실 문제, (4) 구체적 비교(XOR 예시 등)
  • 감점 사유: “활성화함수가 뉴런을 켜고 끈다”만 쓰면 중 이하 / ReLU와 Sigmoid의 차이를 안 쓰면 하

A2. 손실함수의 역할 (“학습”과 “최적화” 포함)

  • 상 필수 요소: (1) “예측과 정답의 차이를 숫자로 측정”, (2) 학습은 손실 최소화 과정, (3) 경사하강법으로 최적화, (4) 손실 최소화 ≠ 정답을 아는 것
  • 감점 사유: “학습”과 “최적화”의 관계를 안 쓰면 중 이하

A3. 경사하강법의 원리 (“기울기”, “학습률”, “최솟값” 포함)

  • 상 필수 요소: (1) 기울기 방향으로 이동, (2) 학습률은 이동 크기, (3) 최솟값에 수렴, (4) 학습률이 너무 크거나 작을 때의 문제
  • 감점 사유: 3개 키워드 중 하나라도 빠지면 중 이하

A4. 활성화함수 3가지 이상 + 각각의 특징

  • 상 필수 요소: (1) Sigmoid, ReLU, Tanh 또는 Leaky ReLU 등 3개 이상, (2) 각각의 수식 또는 특성, (3) 장단점 비교
  • 감점 사유: 이름만 나열하고 특징 설명이 없으면 하

B1. 단층 퍼셉트론이 XOR을 못 푸는 이유 (좌표평면 활용)

  • 상 필수 요소: (1) XOR 4개 점의 좌표 배치, (2) “어떤 직선을 그어도” 분리 불가능, (3) 대각선 배치 설명, (4) 다층 신경망의 필요성 언급
  • 감점 사유: 좌표평면 없이 “직선으로 안 된다”만 쓰면 중

B2. 활성화함수를 모두 제거하면?

  • 상 필수 요소: (1) 선형 변환의 합성은 선형 변환, (2) 다층이어도 단층과 같은 표현력, (3) XOR 분류 불가능, (4) “비선형성이 공간을 구부린다” 개념
  • 감점 사유: “비선형성이 없어서 못 푼다”만 쓰면 중

C1. ChatGPT의 환각 (토큰화, 확률적 예측, 손실함수, 학습 데이터 포함)

  • 중 (1017): 4개 개념 중 23개를 활용하여 설명하되, 인과관계 연결이 부분적

섹션 제목: “이전 차시 복습 포인트 (9차시 → 10차시)”

“지난 시간에 7편의 논문 카드를 탐험하면서, 모든 돌파에는 이전의 좌절이 있었다는 것을 확인했어요. 마지막 카드(GPT-3/ChatGPT)에 ‘남은 질문’이 있었죠 — 환각, 산술 오류, 논리적 실수. 오늘은 이 한계를 직접 실험합니다.”

  • 9차시 카드 7의 “남은 질문”이 10차시의 출발점임을 연결합니다
  • “한계가 있다는 것은 다음 돌파의 씨앗”이라는 9차시의 메시지를 환기합니다

전체 과정 마무리 포인트 (10차시 → 수업 종료)

섹션 제목: “전체 과정 마무리 포인트 (10차시 → 수업 종료)”

“1차시에서 ‘기계가 생각할 수 있는가?‘라는 질문으로 시작해서, 10차시에서 같은 질문으로 끝납니다. 달라진 것은 질문이 아니라, 여러분의 답의 깊이입니다. 같은 질문, 다른 깊이 — 이것이 학습의 증거입니다.”

  • 수업 전체가 “원을 그리며 돌아온 질문” 구조임을 강조합니다
  • 서술형 평가는 “이 깊이를 증명하는 기회”임을 안내합니다
