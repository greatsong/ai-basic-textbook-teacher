배경 지식: 교사가 알아두면 좋은 것

섹션 제목: “배경 지식: 교사가 알아두면 좋은 것”

역전파(Backpropagation)의 역사

  • 핵심 아이디어: 출력의 오차를 입력 방향으로 거꾸로 추적하면서, 각 가중치가 오차에 “얼마나 책임이 있는지”를 계산
  • 수학적 기초: 합성함수의 연쇄법칙(Chain Rule) — “최종 결과의 변화 = 각 단계 변화의 곱”
  • 1970년대: 핀란드의 세포 린나인마(Linnainmaa)가 자동 미분에서 유사 아이디어 제시
  • 1974년: 폴 워보스(Paul Werbos)가 박사논문에서 신경망에 적용 제안 → 거의 주목받지 못함
  • 1986년: 럼멜하트(Rumelhart), 힌튼(Hinton), 윌리엄스(Williams)가 Nature 논문으로 발표 → 학계 전체의 관심
  • 이 알고리즘 덕분에 2층 이상의 신경망도 학습 가능 → 딥러닝의 문을 연 핵심 기술

학생에게 어느 정도까지 말할 것인가:

  • 1986년 Nature 논문, 세 사람의 이름 → 역사 공개 파트에서 (수업 마지막)
  • 연쇄법칙의 수식 → 심화 학생에게만 (교과서 심화 박스 참조)
  • “오차의 책임을 거꾸로 추적” → 핵심 직관, 반드시 전달
  • 기울기 소실(vanishing gradient) → 3차시 ReLU와 연결 가능한 심화 내용

반응대응
”역전파가 뭔데요?""이름만 들으면 어려운데, 하나씩 따라가면 생각보다 직관적이에요. 먼저 숫자를 따라가봅시다."
"이건 어렵겠다…""실은 사칙연산밖에 안 써요. 계산기도 쓸 수 있고요. 직접 해보면 ‘별거 아니네’ 할 거예요."
"5차시에서 한 거랑 뭐가 달라요?""5차시는 ‘어디로 가야 하는지’ 알았을 때 움직이는 방법이었어요. 오늘은 그 ‘어디로’를 구하는 방법이에요.”

주의: 학생들이 “이건 어렵겠다”는 선입견을 가질 수 있습니다. 도입에서 “거꾸로 보내자”라는 아이디어가 직관적임을 강조하세요. 축제 비유를 적극 활용합니다.

순전파 계산 진행

섹션 제목: “순전파 계산 진행”

진행 방식:

  1. 교과서의 ForwardPassCalculator 시뮬레이터를 연다
  2. 2-1-1 네트워크의 구조를 판서로 먼저 설명한다 (입력 2개 → 은닉 1개 → 출력 1개)
  3. 학생이 직접 가중합을 계산하여 입력란에 입력한다
  4. 정답이면 다음 단계, 오답이면 힌트 제공

핵심 숫자 (학생이 따라가야 할 계산)

섹션 제목: “핵심 숫자 (학생이 따라가야 할 계산)”
단계계산결과
은닉 뉴런 가중합z₁ = 0.3 x 1.0 + 0.7 x 0.5 + 0.10.75
Sigmoid 통과a₁ = σ(0.75) = 1 / (1 + e^(-0.75))≈ 0.679
출력 뉴런 가중합z₂ = 0.5 x 0.679 + 0.2≈ 0.540
출력ŷ = σ(0.540)≈ 0.632
오차(MSE)(0.632 - 1.0)²≈ 0.135

1”역전파는 왜 앞으로가 아니라 뒤로 계산하나요?""신경망은 ‘함수 안의 함수’ 구조(합성함수)입니다. 출력의 오차를 입력 방향으로 분해하려면, 출력부터 거꾸로 풀어나가는 것이 가장 효율적이에요. 마치 실타래가 엉켜 있을 때 끝에서부터 풀어가는 것처럼요.”
2”모든 가중치가 똑같이 바뀌면 안 되나요?""그러면 오차에 책임이 큰 가중치와 작은 가중치를 구별하지 않는 거예요. 축제가 망했을 때 모든 사람에게 같은 벌점을 준다면, 진짜 원인이 고쳐지지 않겠죠.”
3”Sigmoid 대신 ReLU를 쓰면 역전파가 달라지나요?""네, 3차시에서 배운 것과 연결돼요. Sigmoid는 미분값이 최대 0.25라서 층이 깊어지면 기울기가 점점 사라져요(기울기 소실). ReLU는 양수 구간에서 미분값이 1이라 기울기가 유지됩니다. 그래서 깊은 네트워크에서는 ReLU가 필수입니다.”
4”역전파를 하면 항상 정답에 도달하나요?""5차시에서 배운 로컬 미니마를 기억하나요? 역전파도 경사하강법을 사용하기 때문에, 전체 최솟값이 아닌 지역 최솟값에 빠질 수 있어요. 하지만 실전에서는 대부분 충분히 좋은 결과를 얻습니다.”
5”연쇄법칙이 뭔가요?""심화 내용이지만 핵심만 말하면, ‘최종 결과가 바뀌는 정도 = 각 단계가 바뀌는 정도를 차례로 곱한 것’입니다. 환율이 1% 바뀌면 원가가 0.5% 바뀌고 판매가가 0.3% 바뀌면, 환율의 최종 영향은 1% x 0.5 x 0.3 = 0.15%인 것처럼요.”
6”실제 AI도 이렇게 손으로 계산하나요?""원리는 정확히 같지만, 실제로는 컴퓨터가 이 계산을 초당 수십억 번 합니다. 여러분이 손으로 따라간 2-1-1 네트워크는 파라미터가 5개인데, GPT-4는 파라미터가 수천억 개예요.”
7”기울기 소실이 뭐예요?""층이 깊어질수록 역전파에서 기울기가 점점 작아져서 앞쪽 층의 가중치가 거의 안 바뀌는 문제예요. Sigmoid의 미분값(최대 0.25)이 계속 곱해지기 때문이에요. ReLU가 이 문제를 해결합니다.”

  • 학습 반복 후 “손실이 줄어드는 이유”를 설명할 수 있는가

섹션 제목: “시나리오 A: 시뮬레이터 전체 접속 불가”

대안 활동 — 종이 + 계산기 순전파 (20분)

  1. 칠판에 2-1-1 네트워크를 그린다
  2. 학생들에게 종이 + 계산기로 순전파 계산을 수행하게 한다
  3. 가중합 → Sigmoid → 오차까지 직접 계산하는 워크시트를 배포한다
  4. 역전파는 “출력 가중치 w₃의 책임이 가장 크다”는 직관적 설명으로 대체한다
  5. “책임의 크기에 비례해서 가중치를 수정한다”는 핵심만 전달

문제 7. 2~6차시 개념 연결 (빈칸 채우기)

섹션 제목: “문제 7. 2~6차시 개념 연결 (빈칸 채우기)”

예시 답안:

차시핵심 개념신경망 학습에서의 역할
2차시퍼셉트론(ㄱ) 신경망의 기본 단위
3차시활성화함수(ㄴ) 다층이 실제로 작동하게 만드는 열쇠 (또는 “공간을 구부려 비선형 문제를 풀 수 있게 한다”)
4차시(ㄷ) 손실함수학습의 목표를 정의
5차시경사하강법(ㄹ) 그 목표에 도달하는 방법 (또는 “기울기를 따라 손실을 줄이는 방법”)
6차시(ㅁ) 역전파다층에서 기울기를 구하는 방법
수준기준배점
상(5점)(ㄱ)~(ㅁ) 모두 정확하고 역할 설명이 구체적5
중(3점)5개 중 3~4개 정확3
하(1점)5개 중 2개 이하 정확1

채점 팁: (ㄱ)(ㄴ)의 역할 설명은 교과서 원문과 완전히 같지 않아도, 핵심 의미가 맞으면 정답으로 처리하세요. 예를 들어 (ㄱ)에 “뉴런을 수학으로 모방한 것”도 정답입니다. (ㄷ)(ㅁ)은 용어 자체가 정확해야 합니다.

  • 문항 7(개념 연결)에서 막히는 학생 → 교과서의 “1~6차시가 하나로 연결됩니다” 표를 함께 읽으며 각 차시의 핵심을 복기
