00-03분: 도입 이야기

섹션 제목: “00-03분: 도입 이야기”

“이 논문이 나오기 전에는, 신경망이 3층만 넘어가도 학습이 안 됐어요. 1층, 2층은 되는데 3층부터는 뒤쪽 가중치가 거의 안 바뀌는 거예요. 연구자 세 명이 해결한 방법은 놀랍도록 직관적이었어요. ‘오차를 거꾸로 보내자.’ 오늘 여러분은 그 과정을 숫자 하나하나까지 직접 따라가게 됩니다.”

교사 주의사항: 학생들이 “이건 어렵겠다”는 선입견을 가질 수 있습니다. 이야기를 통해 “거꾸로 보내자”라는 아이디어가 직관적임을 강조하세요.

03-20분: Phase 1~2 — 순전파 직접 계산 + 오차 계산

섹션 제목: “03-20분: Phase 1~2 — 순전파 직접 계산 + 오차 계산”

진행 방식:

  1. 교과서의 ForwardPassCalculator 시뮬레이터를 연다
  2. 2-1-1 네트워크의 구조를 판서로 먼저 설명한다 (입력 2개 → 은닉 1개 → 출력 1개)
  3. 학생이 직접 가중합을 계산하여 입력란에 입력한다
  4. 정답이면 다음 단계, 오답이면 힌트 제공

핵심 숫자 (학생이 따라가야 할 계산):

  • 은닉 뉴런 가중합: z₁ = 0.3 × 1.0 + 0.7 × 0.5 + 0.1 = 0.75
  • Sigmoid 통과: a₁ = σ(0.75) ≈ 0.679
  • 출력 뉴런 가중합: z₂ = 0.5 × 0.679 + 0.2 ≈ 0.540
  • 출력: ŷ = σ(0.540) ≈ 0.632
  • 오차(MSE): (0.632 - 1.0)² ≈ 0.135

운영 팁: 계산이 느린 학생에게는 “계산기 사용 OK”를 먼저 안내하세요. 중요한 것은 계산 속도가 아니라 “뉴런이 숫자를 어떻게 처리하는가”를 체험하는 것입니다.

20-35분: Phase 3 — 역전파 애니메이션 + 이론

섹션 제목: “20-35분: Phase 3 — 역전파 애니메이션 + 이론”

진행 순서:

  1. “이 오차 0.135를 줄이려면, 어떤 가중치를 바꿔야 할까?” — 학생에게 먼저 질문한다
  2. 학생 예측을 3~4명 받은 뒤, BackpropAnimation 시뮬레이터를 실행한다
  3. 빨간 오차 신호가 역방향으로 이동하는 것을 관찰하게 한다
  4. 각 가중치의 업데이트 전후 값(“0.30 → 0.27”)을 비교하게 한다
  5. BackpropToggle (역전파 ON/OFF 비교) 시뮬레이터로 차이를 확인한다

핵심 직관 전달 (반드시 강조):

“역전파의 아이디어는 이거예요. 최종 오차가 0.135였다고 합시다. 이 오차에 대해 각 가중치가 얼마나 책임이 있는지를 거꾸로 추적하는 겁니다. 출력에 가까운 가중치는 책임이 크고, 입력에 가까운 가중치는 책임이 작을 수 있어요.”

비유 활용: “학교 축제 공연이 실패했을 때, 무대 위 공연자의 책임과, 한 달 전 곡 선정자의 책임이 다른 것처럼.”

35-47분: 반복 학습 — 학습 버튼 반복 + 전체 개념 통합

섹션 제목: “35-47분: 반복 학습 — 학습 버튼 반복 + 전체 개념 통합”

진행 방식:

  1. BackpropTrainer 시뮬레이터에서 학습 버튼을 10회 클릭 → 손실 감소 관찰
  2. 100회까지 반복 → 손실이 거의 0에 수렴하는 것을 확인
  3. 전체 학습 사이클 4단계(순전파 → 오차 → 역전파 → 업데이트) 정리

통합 질문:

“4차시 손실함수 → 5차시 경사하강법 → 6차시 역전파, 이 세 개가 합쳐지면 무엇이 가능해질까요? → 신경망이 스스로 학습할 수 있게 됩니다.”

시뮬레이터 운영 가이드

섹션 제목: “시뮬레이터 운영 가이드”

ForwardPassCalculator (순전파 계산기)

섹션 제목: “ForwardPassCalculator (순전파 계산기)”
  • 소요 시간: 약 12-15분
  • 주요 기능: 학생이 가중합, 활성화함수 결과, 오차를 직접 계산하여 입력
  • 교사 팁: 첫 번째 가중합 계산에서 막히는 학생이 많습니다. “w₁ × x₁ + w₂ × x₂ + b₁ 을 대입해보세요”라고 구체적으로 안내하세요.
  • 자주 발생하는 오류: Sigmoid 계산에서 e⁻⁰·⁷⁵를 구할 때 계산기 사용법을 모르는 경우 → “1 / (1 + 0.4724)” 형태로 안내

BackpropAnimation (역전파 애니메이션)

섹션 제목: “BackpropAnimation (역전파 애니메이션)”
  • 소요 시간: 약 5-7분
  • 주요 기능: 빨간 오차 신호가 출력→입력 방향으로 이동, 가중치 업데이트 전후 표시
  • 교사 팁: 애니메이션을 한 번 보여준 뒤, 학생이 직접 한 번 더 실행하게 하세요.

BackpropToggle (역전파 ON/OFF 비교)

섹션 제목: “BackpropToggle (역전파 ON/OFF 비교)”
  • 소요 시간: 약 3-5분
  • 주요 기능: 역전파 OFF 상태에서 학습 시 은닉층 가중치 변화 없음 → ON 전환 후 모든 층 업데이트 확인
  • 교사 팁: “OFF일 때 은닉층이 왜 안 바뀌는지”를 질문으로 유도하면, 역전파의 필요성을 체감할 수 있습니다.

BackpropTrainer (반복 학습 훈련기)

섹션 제목: “BackpropTrainer (반복 학습 훈련기)”
  • 소요 시간: 약 5-7분
  • 주요 기능: 학습 버튼을 반복 클릭하며 손실 그래프가 실시간으로 감소하는 것을 관찰
  • 교사 팁: “10번 → 50번 → 100번” 단계적으로 클릭하며 손실 곡선의 변화를 관찰하게 하세요.

학생 예상 질문 & 답변

섹션 제목: “학생 예상 질문 & 답변”

Q1. 역전파는 왜 앞으로가 아니라 뒤로 계산하나요?

“신경망은 ‘함수 안의 함수’ 구조(합성함수)입니다. 출력의 오차를 입력 방향으로 분해하려면, 출력부터 거꾸로 풀어나가는 것이 가장 효율적이에요. 마치 실타래가 엉켜 있을 때 끝에서부터 풀어가는 것처럼요.”

Q2. 모든 가중치가 똑같이 바뀌면 안 되나요?

“그러면 오차에 책임이 큰 가중치와 작은 가중치를 구별하지 않는 거예요. 축제가 망했을 때 모든 사람에게 같은 벌점을 준다면, 진짜 원인이 고쳐지지 않겠죠.”

Q3. Sigmoid 대신 ReLU를 쓰면 역전파가 달라지나요?

“네, 3차시에서 배운 것과 연결돼요. Sigmoid는 미분값이 최대 0.25라서 층이 깊어지면 기울기가 점점 사라져요(기울기 소실). ReLU는 양수 구간에서 미분값이 1이라 기울기가 유지됩니다. 그래서 깊은 네트워크에서는 ReLU가 필수입니다.”

Q4. 역전파를 하면 항상 정답에 도달하나요?

“5차시에서 배운 로컬 미니마를 기억하나요? 역전파도 경사하강법을 사용하기 때문에, 전체 최솟값이 아닌 지역 최솟값에 빠질 수 있어요. 하지만 실전에서는 대부분 충분히 좋은 결과를 얻습니다.”

Q5. 연쇄법칙이 뭔가요?

“심화 내용이지만 핵심만 말하면, ‘최종 결과가 바뀌는 정도 = 각 단계가 바뀌는 정도를 차례로 곱한 것’입니다. 환율이 1% 바뀌면 원가가 0.5% 바뀌고 판매가가 0.3% 바뀌면, 환율의 최종 영향은 1% × 0.5 × 0.3 = 0.15%인 것처럼요.”

Q6. 실제 AI도 이렇게 손으로 계산하나요?

“원리는 정확히 같지만, 실제로는 컴퓨터가 이 계산을 초당 수십억 번 합니다. 여러분이 손으로 따라간 2-1-1 네트워크는 파라미터가 5개인데, GPT-4는 파라미터가 수천억 개예요.”

  • 역전파는 미적분의 연쇄법칙을 신경망에 적용한 것
  • 핵심 직관: “최종 결과의 변화량 = 각 단계의 변화량을 차례로 곱한 것”
