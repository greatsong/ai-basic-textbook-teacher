학습 목표경사하강법의 원리를 직관적으로 이해할 수 있다.

수업 준비물

섹션 제목: “수업 준비물”
구분항목비고
필수컴퓨터실 (학생 1인 1PC)시뮬레이터 3종 사용
필수프로젝터 / 대형 디스플레이3D 레이싱 시연, 팀 순위 표시용
필수3D 레이싱 시뮬레이터 (GradientDescentRacing)1차 직감 도전 + 2~3차 전략 도전
필수학습률 비교 시뮬레이터 (LearningRateComparison)학습률 효과 시각화
필수로컬 미니마 시뮬레이터 (LocalMinimaVisualization)가짜 바닥 체험
필수타이머 앱레이싱 시간 관리용
선택팀 편성표2~3인 팀 구성
선택순위 기록 칠판/시트팀별 최저 손실값 기록

사전 점검 사항:

  • 3D 레이싱 시뮬레이터의 “initial” 모드와 “strategic” 모드 전환 확인
  • 팀 편성 사전 결정 (2~3인 1팀, 팀 내 토의 가능한 자리 배치)
  • 순위 기록 방식 결정 (칠판, 스프레드시트 등)

수업 흐름 (50분)

섹션 제목: “수업 흐름 (50분)”
시간활동교사 역할핵심 포인트
00-03분도입 이야기”안개 낀 산” 비유로 시작단순한 규칙의 위력과 함정 예고
03-20분실습1: 3D 레이싱 1차 도전규칙 안내, 직감으로 도전하게 함학습률 효과를 직접 체험 (발산, 정체, 성공)
20-33분이론 설명업데이트 규칙, 학습률, 로컬 미니마, 모멘텀숫자 예시로 직관적 이해
33-48분실습2: 전략적 재도전 2~3회팀 토의 유도, 순위 관리이론 → 전략 → 결과 개선
48-50분역사 공개코시(1847), GPU 혁명180년 전 수학 + 게임용 칩 = AI

교사 발화 예시

섹션 제목: “교사 발화 예시”

도입 (00-03분)

섹션 제목: “도입 (00-03분)”

“여러분이 안개 낀 산꼭대기에 서 있다고 상상해보세요. 앞이 안 보여요. 어떻게 내려갈 수 있을까요?”

(1~2초 대기)

“발밑을 더듬어보면 돼요. 기울어진 쪽으로 한 걸음 내딛는 거죠. 그런데 한 걸음을 얼마나 크게 내디뎌야 할까요? 너무 크게 뛰면 낭떠러지에서 떨어지고, 너무 작게 움직이면 날이 저물어버려요.”

“지난 시간에 손실 등고선에서 ‘화살표를 따라가면 된다’고 했죠? 오늘 그 화살표를 직접 따라가는 레이싱을 합니다.”

1차 도전 전 (03분)

섹션 제목: “1차 도전 전 (03분)”

“3D 손실 지형 위에 공이 하나 놓여 있어요. 이 공을 가장 낮은 골짜기에 보내는 게 목표입니다.”

“두 가지를 설정할 수 있어요. 학습률 — 공이 한 번에 얼마나 멀리 굴러갈지. 모멘텀 — 공에 관성을 줄지 말지.”

“첫 번째 도전은 아무 설명 없이 시작합니다. 직감으로 설정하고 ‘출발!’을 누르세요.”

1차 도전 후 관찰 유도 (15분)

섹션 제목: “1차 도전 후 관찰 유도 (15분)”

“결과가 어땠어요? 공이 거의 안 움직인 팀? 공이 날아가버린 팀? 공이 부드럽게 내려간 팀?”

“적당하게 설정했는데 가장 낮은 곳이 아닌 다른 웅덩이에서 멈춘 팀 있나요? 그건 세팅 문제가 아닙니다. 출발 위치가 달랐기 때문이에요.”

이론 핵심 멘트 (20-33분)

섹션 제목: “이론 핵심 멘트 (20-33분)”

“경사하강법의 업데이트 규칙은 딱 한 줄이에요. 새 위치 = 현재 위치 - 학습률 x 기울기.”

“숫자로 볼게요. w = 5.0이고 기울기가 -3이면…” “학습률 0.1이면 → 5.0 - 0.1 x (-3) = 5.3. 조금 이동. 안전하지만 느려요.” “학습률 0.5면 → 6.5. 적당히 이동.” “학습률 2.0이면 → 11.0. 너무 크게 뜀! 방금 레이싱에서 공이 날아간 팀, 이게 원인이에요.”

“기울기는 ‘어디로 가야 손실이 줄어드는지’ 알려주는 나침반. 학습률은 ‘한 걸음 크기’. 방금 레이싱에서 겪은 것과 정확히 같아요.”

로컬 미니마 설명 (27분)

섹션 제목: “로컬 미니마 설명 (27분)”

“적절한 학습률을 설정했는데도 가장 낮은 곳이 아닌 다른 곳에서 멈춘 팀 기억나죠? 이 웅덩이를 로컬 미니마라고 해요. 주변보다는 낮지만, 전체에서 가장 낮은 곳은 아닌 지점.”

“안개 속에서 ‘여기가 바닥이다’ 하고 멈추지만, 안개가 걷히면 저 멀리 더 깊은 계곡이 보이는 거예요.”

모멘텀 설명 (30분)

섹션 제목: “모멘텀 설명 (30분)”

“실제 공을 굴릴 때 작은 웅덩이를 만나면 어떻게 되죠? 굴러온 힘으로 넘어가죠. 이 물리적 직관을 그대로 적용한 게 모멘텀이에요.”

“모멘텀을 높이면 관성이 생겨서 작은 언덕을 넘을 수 있어요. 스케이트보드가 U자 반파이프를 타는 것처럼.”

2차 도전 유도 (33분)

섹션 제목: “2차 도전 유도 (33분)”

“이제 원리를 알았으니 전략을 세워봅시다. 팀원들과 토의하세요 — 학습률을 얼마로 할지, 모멘텀을 줄지 말지.”

“2~3회 도전 기회가 있습니다. 최저 손실값에 도달하는 시간으로 팀별 순위를 매깁니다.”

역사 공개 (48분)

섹션 제목: “역사 공개 (48분)”

“이 ‘기울기를 따라 내려가기’ 방법. 코시라는 수학자가 1847년에 발명했어요. 180년 전이에요.”

“그리고 2012년, 한 팀이 깨달았어요 — 게임용 그래픽 카드 GPU가 이 계산을 엄청나게 빨리 할 수 있다는 걸. NVIDIA는 게이머를 위해 만든 칩이 AI를 위해 쓰일 줄 몰랐어요.”

시뮬레이터 운영 가이드

섹션 제목: “시뮬레이터 운영 가이드”

실습1: 3D 레이싱 1차 도전 (GradientDescentRacing, initial 모드)

섹션 제목: “실습1: 3D 레이싱 1차 도전 (GradientDescentRacing, initial 모드)”
항목내용
사용 시점실습1 (03-20분)
예상 소요 시간규칙 안내 3분 + 설정/도전 7분 + 결과 관찰/토의 7분 = 약 17분
핵심 설정학습률 슬라이더 + 모멘텀 슬라이더 + “출발!” 버튼
팀 운영2~3인 1팀, 팀 내 토의 후 한 명이 조작

운영 팁:

  • 1차 도전은 아무 설명 없이 시작하세요 — 직감 도전이 핵심
  • 팀마다 다른 초기 위치가 배정되므로, 같은 설정이라도 결과가 다릅니다
  • 세 가지 유형의 결과를 반드시 관찰하세요:
    • 학습률 너무 작음 → 거의 안 움직임
    • 학습률 너무 큼 → 발산/진동
    • 로컬 미니마에 갇힘 → “왜 저기서 멈추지?”
  • 각 유형을 경험한 팀에게 발표시키면 이론 설명의 도입이 됩니다

학습률 비교 (LearningRateComparison)

섹션 제목: “학습률 비교 (LearningRateComparison)”
항목내용
사용 시점이론 설명 (20-33분) 중 데모
예상 소요 시간교사 시연 + 학생 체험 = 약 5분
핵심 체험학습률 크기에 따른 수렴/발산 비교를 한눈에 확인

운영 팁:

  • 학습률 0.001, 0.1, 2.0을 동시에 보여주면 효과적
  • “너무 작으면 평생 도착 못 하고, 너무 크면 산 밖으로 날아간다”는 비유와 연결

로컬 미니마 (LocalMinimaVisualization)

섹션 제목: “로컬 미니마 (LocalMinimaVisualization)”
항목내용
사용 시점이론 설명 (27-30분)
예상 소요 시간시연 + 토의 = 약 3분
핵심 체험로컬 미니마에 빠진 공이 모멘텀으로 탈출하는 과정 시각화

실습2: 전략적 재도전 (GradientDescentRacing, strategic 모드)

섹션 제목: “실습2: 전략적 재도전 (GradientDescentRacing, strategic 모드)”
항목내용
사용 시점실습2 (33-48분)
예상 소요 시간전략 토의 3분 + 2~3차 도전 각 3분 + 순위 발표/비교 3분 = 약 15분
핵심 경험1차(직감) vs 2~3차(전략)의 결과 비교 → “이론을 알면 전략이 생긴다”

운영 팁:

  • 팀 내 토의를 반드시 유도하세요: “학습률 몇으로 할래?”, “모멘텀 줄까?”
  • 구체적 숫자로 전략을 세우게 하세요 — “0.1에 모멘텀 0.9로 가자” 식으로
  • 1차 결과와 2~3차 결과를 나란히 비교하면 “지식의 실용적 가치”가 체감됩니다
  • 최종 순위 발표 시 “같은 설정인데 시작점 때문에 결과가 달랐다” 포인트도 짚어주세요

학생 예상 질문 & 답변

섹션 제목: “학생 예상 질문 & 답변”
#예상 질문교사 답변 가이드
1”학습률을 자동으로 정해주면 안 돼요?""실제로 그런 방법들이 있어요. Adam 같은 최적화 알고리즘은 학습률을 자동으로 조절해요. 하지만 기본 원리를 아는 게 먼저입니다.”
2”로컬 미니마에 빠지면 답이 없어요?""모멘텀이 도움이 되고, 랜덤한 시작점을 여러 번 시도하는 방법도 있어요. 실제 딥러닝에서는 파라미터가 너무 많아서 완벽한 로컬 미니마보다 안장점(saddle point)이 더 큰 문제예요.”
3”GPU가 왜 AI에 좋아요?""경사하강법은 ‘모든 가중치에 대해 같은 계산을 반복’하는 거예요. GPU는 수천 개의 단순 계산을 동시에 처리하도록 설계됐어요. 딱 맞는 거죠.”
4”파라미터가 2개인데 수천억 개면 어떡해요?""원리는 완전히 같아요. 다만 계산량이 상상할 수 없이 커지는 거죠. 그래서 GPU 수천 개가 며칠 밤낮으로 돌아가는 겁니다.”
5”기울기가 0이면 어떻게 돼요?""멈춥니다. 그곳이 최적점이면 좋지만, 로컬 미니마이거나 안장점일 수도 있어요. 모멘텀이 있으면 관성으로 빠져나올 수 있습니다.”
6”실제 AI 학습에서 학습률은 보통 얼마예요?""0.001에서 0.1 사이의 아주 작은 값을 써요. 파라미터가 수억 개일 때는 한 걸음이 아주 작아야 정밀하게 최적점에 도달할 수 있거든요.”

시나리오 A: 3D 레이싱 시뮬레이터 장애

섹션 제목: “시나리오 A: 3D 레이싱 시뮬레이터 장애”

대안 활동 — 보드게임 경사하강법 (25분)

  1. 모눈종이에 간단한 2D 등고선 지도를 그림 (교사가 미리 준비)
  2. 각 팀에 주사위 1개, 지우개(공 역할) 1개 배부
  3. 시작점을 팀마다 다르게 배정
  4. 턴마다:
    • 현재 위치에서 “기울기 방향”을 교사가 알려줌 (또는 등고선에서 학생이 추정)
    • 주사위로 학습률 결정: 1-2 = 작은 걸음, 3-4 = 적당한 걸음, 5-6 = 큰 걸음
    • 해당 방향으로 이동
  5. 가장 빨리 “가장 낮은 곳”에 도달한 팀이 승리
  6. 큰 걸음(5-6)이 나왔을 때 목표를 지나치는 경험 → “학습률이 크면 발산” 체감

GPU와 AI의 관계

섹션 제목: “GPU와 AI의 관계”
  • GPU(Graphics Processing Unit): 원래 게임 그래픽 렌더링용
  • GPU의 핵심 능력: 수천 개의 단순 계산을 동시에 처리 (병렬 처리)
  • 경사하강법은 “모든 가중치에 대해 같은 계산을 반복” → GPU에 딱 맞는 작업
  • 2012년 AlexNet이 NVIDIA GPU 2개로 학습에 성공 → AI 분야에서 GPU 사용 폭발
  • NVIDIA의 시가총액이 3조 달러를 넘긴 배경에는 이 연결이 있음

“기울기를 따라 내려가면 된다는 것은 알았어요. 그런데 — 층이 여러 개일 때, 각 층의 기울기는 어떻게 구할까요? 입력에서 멀리 떨어진 가중치의 기울기는?”
