섹션 제목: “실습 가이드: 다음 단어 예측 게임 (슬라이드 #4~6)”

배경 지식: 교사가 알아두면 좋은 것

섹션 제목: “배경 지식: 교사가 알아두면 좋은 것”

언어 모델(Language Model)의 본질

  • 언어 모델은 “주어진 문맥에서 다음 토큰이 무엇인지 확률 분포를 계산하는 함수”입니다
  • P(다음 토큰 | 이전 토큰들) — 이 하나의 수식이 GPT, Claude, Gemini 등 모든 대형 언어 모델의 핵심
  • ChatGPT가 문장을 생성하는 것은 이 확률 분포에서 토큰을 하나 뽑고, 그것을 입력에 추가하고, 다시 확률 분포를 계산하는 것을 반복하는 과정(autoregressive generation)
  • 수십억 개의 텍스트에서 학습한 확률 분포가 “상식”처럼 보이는 것

Temperature의 수학적 원리

  • 신경망이 각 단어에 매긴 원점수를 로짓(logit)이라 부릅니다
  • 로짓을 Temperature(T)로 나눈 뒤 소프트맥스 함수를 적용합니다: P(단어i) = exp(logit_i / T) / sum(exp(logit_j / T))
  • T가 0에 가까우면: 가장 큰 로짓이 압도적 확률 → 항상 같은 답
  • T가 무한대면: 모든 단어가 균등한 확률 → 완전 무작위
  • 실제 ChatGPT에서 코드 생성은 T=0.2, 창의적 글쓰기는 T=0.8~1.0 정도

학생에게 어느 정도까지 말할 것인가:

  • “로짓을 Temperature로 나눈다” → 수업에서 사용 가능 (교과서에도 있음)
  • 소프트맥스 수식 → 불필요. “점수를 확률로 바꾸는 과정”이면 충분
  • autoregressive generation → “단어를 하나 고르고, 그걸 입력에 추가하고, 다시 고르기를 반복” 정도로 설명

실험 설계

섹션 제목: “실험 설계”

진행 순서:

  1. NextWordPrediction 시뮬레이터를 열게 한다
  2. “오늘 점심에 나는 ___을 먹었다” — 학생이 먼저 빈칸 예측 입력
  3. AI의 예측을 확률 분포 막대그래프로 확인 (밥 35%, 김치 12%, 피자 8%…)
  4. “한국의 수도는 ___이다” — 특정 단어가 압도적 확률을 차지하는 경우
  5. Temperature 슬라이더를 조절하며 출력 변화 관찰
  6. 존재하지 않는 사실에 대한 질문 → 그럴듯한 답 생성(환각 체험)

교사 멘트 (실습 전)

섹션 제목: “교사 멘트 (실습 전)”

“지금부터 실습을 합니다. 교과서에 있는 ‘다음 단어 예측기’를 열어주세요.”

4”환각을 완전히 없앨 수 있나요?""다음 토큰을 확률적으로 예측하는 구조가 바뀌지 않는 한, 완전히 없앨 수는 없어요. 줄일 수는 있지만요.”

6”트랜스포머 이전의 RNN은 왜 잊어버리나요?""순서대로 처리하면서 앞 단어의 정보를 ‘요약’해서 넘기는데, 요약을 반복하면 정보가 손실돼요. 트랜스포머는 전체를 한 번에 보니 이 문제가 없습니다.”
7”ChatGPT도 ‘중국어 방’인 건가요?""아주 좋은 연결이에요! 1차시의 중국어 방을 떠올려보세요. ChatGPT도 결국 규칙(수천억 파라미터)에 따라 출력을 만들어내는 구조예요. 이것이 ‘이해’인지는 여전히 열린 질문입니다.”

Temperature는 AI가 학습하는 데이터의 양을 조절하는 값이다

해설: Temperature는 학습 데이터의 양과 무관합니다. Temperature는 AI가 다음 단어를 선택할 때 얼마나 모험적으로 선택할지를 조절하는 값입니다. 로짓(각 단어의 원점수)을 Temperature 값으로 나눈 뒤 확률로 변환하여, 값이 낮으면 1등만 살아남고 높으면 여러 단어가 비슷한 확률을 갖게 됩니다.

문제 3. 어텐션의 역할 (객관식)

섹션 제목: “문제 3. 어텐션의 역할 (객관식)”

정답: ②

“나는 프랑스에서 태어나서”

해설: 빈칸에 “프랑스어”를 예측하기 위해서는 “프랑스에서 태어나서”라는 핵심 단서에 주목해야 합니다. “초등학교”, “중학교” 같은 중간 단어들은 이 예측에 상대적으로 덜 중요합니다. 이것이 어텐션의 핵심 — 관련 있는 단어에 강하게 주목하고, 관련 없는 것은 무시하는 것입니다.

문제 4. 트랜스포머와 RNN 비교 (객관식)

섹션 제목: “문제 4. 트랜스포머와 RNN 비교 (객관식)”

정답: ①, ②

해설:

  • ① 트랜스포머는 문장의 모든 단어를 병렬로 동시에 처리합니다 (RNN은 순서대로 하나씩).
  • ② 어텐션으로 문장 전체를 한 번에 보므로, 아무리 긴 문장이라도 앞부분을 잊지 않습니다.
  • ③ 트랜스포머도 학습 데이터가 반드시 필요합니다 (수십억 개의 텍스트).
  • ④ 트랜스포머의 파라미터 수가 반드시 적은 것은 아닙니다. GPT-4는 추정 수천억~수조 개의 파라미터를 사용합니다.

문제 5. 환각의 구조적 원인 (서술형)

섹션 제목: “문제 5. 환각의 구조적 원인 (서술형)”

예시 답안:

AI가 하는 일의 본질은 “학습 데이터에서 가장 가능성 높은 다음 단어를 예측하는 것”입니다. 학습 데이터에 정답이 있는 질문에는 높은 확률로 정확한 단어를 선택하지만, 학습 데이터에 정답이 없는 질문(예: 존재하지 않는 논문)에도 AI의 메커니즘은 항상 다음 단어를 예측합니다. “모르겠습니다”라고 멈추는 것이 아니라, 가장 그럴듯한 단어를 이어붙이는 것입니다. 따라서 환각은 AI가 “멍청해서” 발생하는 버그가 아니라, “다음 토큰의 확률을 예측하는” 기본 구조의 필연적 결과입니다.

채점 기준 (루브릭):

수준기준배점
상(5점)“다음 단어 예측”이라는 원리를 정확히 근거로 제시하고, 학습 데이터에 정답이 있는 경우/없는 경우를 대비하여 환각이 구조적 필연임을 논리적으로 설명5
중(3점)“다음 단어 예측” 원리를 근거로 언급하고 환각의 구조적 성격을 설명하나, 논리 전개가 다소 불완전3
하(1점)환각이 발생하는 이유를 대략 이해하나, “다음 단어 예측” 원리와의 연결이 불명확1

문제 6. 전체 파이프라인 정리 (서술형)

섹션 제목: “문제 6. 전체 파이프라인 정리 (서술형)”

예시 답안:

  1. 토큰화: “오늘 날씨가 좋아서 산책을”이라는 문장을 토큰이라는 작은 조각으로 쪼갭니다.
  2. 임베딩: 각 토큰을 의미가 담긴 숫자 벡터로 변환합니다. 의미가 비슷한 단어는 비슷한 벡터를 가집니다.
  3. 어텐션: 각 토큰이 다른 토큰과 얼마나 관련 있는지를 계산합니다. 예를 들어 “산책을”이라는 단어가 “좋아서”와 강하게 연결됩니다.
  4. 신경망 처리: 여러 층의 신경망을 통과하며 정보를 처리합니다.
  5. 확률 출력: 다음 토큰으로 올 수 있는 모든 단어의 확률을 계산합니다 (갔습니다 40%, 했습니다 15%, 나갔습니다 10%…).
  6. 선택: Temperature에 따라 확률 분포에서 하나의 단어를 선택합니다. 여기서 “갔습니다”가 선택됩니다.

그리고 선택된 “갔습니다”를 입력에 추가하여 1~6을 반복하면, 문장이 계속 이어집니다.

채점 기준 (루브릭):

수준기준배점
상(5점)6단계를 모두 순서대로 설명하고, 각 단계가 하는 일을 구체적으로 서술. “반복”까지 언급하면 만점5
중(3점)주요 단계(토큰화, 임베딩, 어텐션, 확률 출력)를 순서대로 설명하나, 일부 단계의 설명이 누락되거나 부족3
하(1점)전체 흐름을 대략 이해하나, 단계별 설명이 부정확하거나 순서가 틀림1

문제 7. “기계가 생각할 수 있는가?” (서술형)

섹션 제목: “문제 7. “기계가 생각할 수 있는가?” (서술형)”

예시 답안 (이해한다는 입장): ChatGPT는 1~8차시에서 배운 원리대로, 토큰화와 임베딩으로 글자를 숫자로 변환하고, 어텐션으로 문맥을 파악하며, 다음 단어를 확률적으로 예측합니다. 중국어 방의 사람처럼 “규칙에 따라 출력을 만들어내는 구조”라는 점에서, 진정한 “이해”가 아니라 할 수 있습니다. 하지만 시스템 반론의 관점에서, 방 안의 사람은 중국어를 모르지만 “방 + 사람 + 매뉴얼” 전체 시스템은 이해하는 것일 수 있습니다. ChatGPT도 수천억 파라미터의 신경망 전체가 하나의 시스템으로서 언어의 패턴과 관계를 포착하고 있으므로, 이것을 일종의 “이해”로 볼 수 있다고 생각합니다.

예시 답안 (이해하지 못한다는 입장): 8차시에서 배운 바에 따르면, ChatGPT가 하는 일의 본질은 “다음 토큰의 확률 분포를 예측하는 것”입니다. 환각이 구조적으로 발생하는 것은, AI가 사실의 진위를 판별하는 것이 아니라 단지 가장 그럴듯한 다음 단어를 이어붙이기 때문입니다. 이것은 중국어 방에서 매뉴얼만 보고 답변하는 사람과 본질적으로 같습니다. “이해”가 세상에 대한 경험적 근거를 포함하는 것이라면, ChatGPT는 언어를 이해하는 것이 아니라 패턴을 매우 잘 모방하는 것이라고 생각합니다.

채점 기준 (루브릭):

수준기준배점
상(5점)중국어 방 사고실험과 8차시의 “다음 단어 예측” 원리를 명확히 연결하고, 자신의 입장(찬성/반대)에 대해 구체적 근거를 제시. 환각, 어텐션, 확률적 예측 등 수업 개념을 활용하여 논증5
중(3점)중국어 방과 AI 원리를 연결하여 의견을 제시하나, 근거가 다소 피상적이거나 수업 개념 활용이 부족3
하(1점)자신의 의견은 있으나, 중국어 방이나 AI 작동 원리와의 연결이 불명확하고 근거가 부족1

채점 유의사항: 이 문항은 정답이 없는 개방형 질문입니다. 찬성/반대 어느 쪽이든 수업에서 배운 개념(다음 단어 예측, 어텐션, 환각, 중국어 방)을 근거로 활용했는지, 논리적으로 일관된 주장을 펼쳤는지를 평가합니다.
