배경 지식: 교사가 알아두면 좋은 것

섹션 제목: “배경 지식: 교사가 알아두면 좋은 것”

토큰화(Tokenization)와 임베딩(Embedding)

  • 토큰화: 문장을 작은 조각(토큰)으로 쪼개는 과정. 단어일 수도 있고, 단어의 일부일 수도 있음

    • 가장 널리 쓰이는 방법: BPE(Byte Pair Encoding) — 자주 붙어 나오는 글자 쌍을 합치는 방식
    • GPT-4의 토크나이저는 약 10만 개의 토큰을 보유
    • 한국어는 영어보다 토큰이 2~3배 더 많이 필요 → 비용, 속도, 품질에 영향

  • 임베딩: 각 토큰을 의미가 담긴 숫자 벡터로 변환하는 것

    • 원-핫 인코딩의 한계: 10만 차원, 모든 단어 간 거리가 동일 → 의미 관계 표현 불가
    • Word2Vec (2013, Mikolov): 수백 차원의 밀집 벡터로 의미를 압축
    • 핵심 원리: 분포 가설(distributional hypothesis) — “비슷한 맥락에서 등장하는 단어는 비슷한 의미를 가진다”
    • 학습 방법: 2~6차시에서 배운 신경망 + 손실함수 + 역전파와 동일한 원리

  • Word2Vec의 두 가지 방식

    • CBOW: 주변 단어 → 가운데 단어 예측 (더 빠름)
    • Skip-gram: 가운데 단어 → 주변 단어 예측 (드문 단어에 강함)
    • 실제 GPT 등 최신 모델은 문맥별로 다른 임베딩(contextualized embedding)을 사용 → 8차시에서 다룸

학생에게 어느 정도까지 말할 것인가:

  • BPE 원리 → 교과서 심화 박스에 있음. 학생이 물으면 “자주 나오는 쌍을 합치는 방식”으로 간결하게
  • Word2Vec 이름, 미콜로프 → 역사 공개 파트에서
  • 분포 가설 → 이론 설명 중에 핵심으로 전달
  • CBOW/Skip-gram → 심화 학생에게만 간략히

교사 멘트 — 문제 제기

섹션 제목: “교사 멘트 — 문제 제기”

“6차시까지 우리는 신경망이 숫자를 입력받아 숫자를 출력하는 기계라는 것을 배웠어요. 그런데 여러분은 매일 ChatGPT에게 ‘글’로 질문하잖아요. 숫자밖에 모르는 기계가 어떻게 글을 처리하는 걸까요?”

“그 비밀의 첫 번째 단계가 토큰화예요. 문장을 작은 조각으로 쪼개는 거예요. 직접 해봅시다.”

토큰화 실습 진행

섹션 제목: “토큰화 실습 진행”

진행 순서:

  1. TokenizerPlayground 시뮬레이터를 열게 한다
  2. “안녕하세요”를 입력 → 토큰 수 예상 vs 실제 비교
  3. 같은 의미 영어 “Hello” 입력 → 토큰 수 차이 관찰
  4. 이모지 입력 → 이것도 토큰으로 처리됨을 확인
  5. 대결: “가장 적은 토큰으로 ‘오늘 점심 뭐 먹었어?‘와 같은 의미를 전달하는 문장 만들기”

“‘안녕하세요’를 입력하기 전에, 이 문장이 몇 개의 토큰으로 나뉠지 예상해보세요. 1개? 2개? 5개?”

(학생 예상을 2~3명 받은 뒤)

“자, 입력해봅시다.”

(학생이 입력한 후)

교사 멘트 — 2단계 (한국어 vs 영어)

섹션 제목: “교사 멘트 — 2단계 (한국어 vs 영어)”

“이번엔 같은 의미의 영어 ‘Hello’를 입력해보세요.”

(학생 반응을 기다림)

“한국어 ‘안녕하세요’가 토큰이 여러 개인데, 영어 ‘Hello’는 하나라고요? 이건 단순한 기술 차이가 아니에요.”

학생 예상 질문 & 답변

섹션 제목: “학생 예상 질문 & 답변”
#예상 질문교사 답변 가이드
1”토큰이 왜 단어 단위로 안 나뉘나요?""토크나이저는 BPE라는 방법으로 자주 나오는 조합을 합칩니다. 영어 ‘the’는 워낙 자주 나오니까 통째로 하나의 토큰이지만, 한국어 글자 조합은 상대적으로 드물어서 더 잘게 나뉘는 거예요.”
2”임베딩 벡터의 각 숫자는 무슨 뜻인가요?""사람이 정해준 게 아닙니다. 기계가 데이터에서 패턴을 찾아 스스로 만든 거예요. 각 차원이 구체적으로 무엇을 의미하는지 사람이 정확히 해석하기 어려운 경우가 많습니다.”
3“‘왕 - 남자 + 여자 = 여왕’이 항상 맞나요?""항상 완벽하진 않아요. 하지만 많은 경우에 놀라울 정도로 잘 맞습니다. ‘파리 - 프랑스 + 일본 ≈ 도쿄’ 같은 관계도 잡아낼 수 있어요. 핵심은 100% 정확한가가 아니라, 단어의 관계가 벡터의 방향으로 포착된다는 것 자체가 혁명적이었다는 거예요.”
4”한국어가 토큰이 더 많으면 AI가 한국어를 더 못하는 건가요?""직접적으로 ‘못하는 것’은 아니지만, 같은 의미를 처리하는 데 더 많은 토큰이 필요하므로 비용이 더 들고 처리가 느려질 수 있어요. 최근에는 한국어에 특화된 토크나이저도 개발되고 있습니다.”
5”임베딩은 어떻게 학습되나요?""2~6차시에서 배운 것과 똑같아요! 거대한 텍스트로 ‘주변 단어를 예측하는’ 신경망을 만들고, 손실함수로 틀린 정도를 재고, 역전파로 가중치를 업데이트합니다. 그 학습된 가중치가 곧 임베딩 벡터입니다.”
6”같은 단어 ‘사과’가 과일과 사과하다 두 가지 뜻이 있는데, 임베딩에서 어떻게 구별하나요?""Word2Vec에서는 구별이 어렵습니다. 하지만 다음 시간에 배울 ‘어텐션’이 바로 이 문제를 해결합니다. 문맥을 보고 같은 단어의 의미를 다르게 파악하는 거예요.”
7”임베딩 벡터는 실제로 몇 차원인가요?""Word2Vec은 보통 100~300차원, GPT-4 같은 최신 모델은 수천 차원을 사용합니다. 교과서에서는 이해를 돕기 위해 3차원으로 단순화한 거예요.”

문제 5. 임베딩의 핵심 원리 (서술형)

토큰 번호는 사전에서의 순서를 나타내는 숫자 하나일 뿐이므로, “좋다/싫다”, “동물/식물” 같은 여러 의미 차원을 담을 수 없습니다. 반면 임베딩 벡터는 여러 개의 숫자 묶음(벡터)으로 단어를 표현하여, 각 숫자가 서로 다른 의미 차원을 담습니다. 그 결과 의미가 비슷한 단어끼리는 비슷한 벡터를 가지게 되어 가까이 배치되고, 의미가 다른 단어끼리는 멀리 배치됩니다. 이렇게 단어의 의미 관계가 벡터 공간의 거리와 방향으로 표현되기 때문에, “왕 - 남자 + 여자 = 여왕” 같은 의미 연산이 가능해집니다.

수준기준배점

중(3점)토큰 번호와 임베딩의 차이를 설명하고, “의미가 비슷한 단어” 표현을 포함하나 설명이 다소 피상적3
하(1점)임베딩이 숫자 묶음이라는 것은 알지만, 토큰 번호와의 차이나 의미 표현 원리를 구체적으로 설명하지 못함1
