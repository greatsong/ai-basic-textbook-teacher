00-03분: 도입 이야기

섹션 제목: “00-03분: 도입 이야기”

“어떤 연구자가 단어를 숫자로 바꾸는 방법을 발견했을 때, 이상한 일이 일어났어요. 컴퓨터에게 ‘왕’이라는 단어에서 ‘남자’를 빼고 ‘여자’를 더하라고 했더니 — ‘여왕’이 나온 겁니다. 컴퓨터가 의미를 이해하는 걸까요? 오늘 여러분이 직접 확인해봅시다.”

교사 주의사항: “왕 - 남자 + 여자 = 여왕”은 이 수업 전체의 킬러 예시입니다. 도입에서 호기심만 유발하고, 왜 이것이 가능한지에 대한 설명은 수업 후반부까지 미루세요.

03-15분: 실습1 — 토큰화 대결

섹션 제목: “03-15분: 실습1 — 토큰화 대결”

진행 순서:

  1. TokenizerPlayground 시뮬레이터를 열게 한다
  2. “안녕하세요”를 입력 → 토큰 수 예상 vs 실제 비교
  3. 같은 의미 영어 “Hello” 입력 → 토큰 수 차이 관찰
  4. 이모지 😀 입력 → 이것도 토큰으로 처리됨을 확인
  5. 대결: “가장 적은 토큰으로 ‘오늘 점심 뭐 먹었어?‘와 같은 의미를 전달하는 문장 만들기”

핵심 서프라이즈:

  • 한 단어(“안녕하세요”)인데 토큰이 여러 개로 나뉨
  • 같은 의미인데 한국어가 영어보다 토큰이 많음
  • 이모지도 토큰으로 처리됨

운영 팁: 토큰화 대결은 자연스럽게 경쟁심을 유발합니다. 2-3분 시간을 주고, “가장 적은 토큰 수”를 보고한 학생의 문장을 공유하세요.

15-28분: 이론 — 토큰화, 임베딩, 의미적 거리

섹션 제목: “15-28분: 이론 — 토큰화, 임베딩, 의미적 거리”

설명 순서:

  1. 토큰이란? — 문장을 쪼갠 조각. 단어일 수도, 단어의 일부일 수도 있음
  2. 토큰 번호의 한계 — “love”=2834, “hate”=7291이면, 이 번호에서 의미 관계를 읽을 수 있나? → 없음
  3. 임베딩의 등장 — 숫자 하나가 아니라, 여러 개의 숫자 묶음(벡터)으로 의미를 표현
  4. 의미적 거리 — 비슷한 의미의 단어는 가까운 벡터, 다른 의미는 먼 벡터

판서 예시 (벡터 연산):

핵심 전환점: “이 숫자는 누가 정한 걸까?” → 사람이 아니라 기계가 학습한 것 → 2~6차시에서 배운 신경망, 손실함수, 역전파가 여기서도 쓰임

28-47분: 실습2 — 임베딩 갤럭시 (3D 멀티플레이어)

섹션 제목: “28-47분: 실습2 — 임베딩 갤럭시 (3D 멀티플레이어)”

진행 순서:

  1. EmbeddingGalaxy 시뮬레이터를 열게 한다
  2. “고양이” 등록 → “강아지” 등록 → 가까이 배치되는지 확인
  3. “바나나” 등록 → “고양이”와 멀리, 과일끼리 가까이
  4. “사과”(과일) 등록 → “바나나” 근처 확인
  5. 친구들과 함께 단어를 등록하며 “의미의 지도” 탐험

운영 팁: 학생들에게 자유롭게 단어를 등록하게 하되, 중간에 한 번 “지금까지 가장 놀라웠던 배치가 뭐였어요?”라고 물어서 관찰 결과를 공유하세요. VectorArithmetic 시뮬레이터도 함께 사용하여 벡터 연산을 직접 체험하게 합니다.

47-50분: 역사 공개

섹션 제목: “47-50분: 역사 공개”

“이 방법을 만든 사람. 토마스 미콜로프, 구글 연구원이었어요. 2013년 Word2Vec이라는 논문을 냈는데, 학계가 뒤집혔어요. ‘왕 - 남자 + 여자 = 여왕’. 의미를 계산할 수 있다는 발상 자체가 혁명이었죠.”

교사 발화 예시

섹션 제목: “교사 발화 예시”

도입부 — 문제 제기

섹션 제목: “도입부 — 문제 제기”

“6차시까지 우리는 신경망이 숫자를 입력받아 숫자를 출력하는 기계라는 것을 배웠어요. 그런데 여러분은 매일 ChatGPT에게 ‘글’로 질문하잖아요. 숫자밖에 모르는 기계가 어떻게 글을 처리하는 걸까요? — 그 비밀이 바로 ‘토큰화’와 ‘임베딩’입니다.”

토큰화 대결 후 — 서프라이즈 강조

섹션 제목: “토큰화 대결 후 — 서프라이즈 강조”

“한국어 ‘안녕하세요’가 토큰이 여러 개인데, 영어 ‘Hello’는 하나라고요? 이건 단순한 기술 차이가 아니에요. AI에게 같은 질문을 해도 한국어는 토큰이 더 많이 들어서, 비용도 더 들고 처리 속도도 느려질 수 있어요. AI 시대에 언어 간 형평성이라는 새로운 문제가 생긴 겁니다.”

임베딩 설명 — 비유 활용

섹션 제목: “임베딩 설명 — 비유 활용”

“토큰 번호는 출석 번호 같은 거예요. 출석 번호 1번과 30번이라고 해서 뭔가 관계가 있는 건 아니잖아요. 임베딩은 프로필 카드에 비유할 수 있어요. 운동 잘하는 정도, 공부 잘하는 정도, 키… 여러 특성을 숫자로 적으면, 비슷한 사람끼리 비슷한 카드를 가지게 되죠.”

임베딩 갤럭시 실습 중 — 관찰 유도

섹션 제목: “임베딩 갤럭시 실습 중 — 관찰 유도”

“‘고양이’와 ‘강아지’가 가까이 있나요? ‘바나나’와는 멀리 있나요? — 의미가 비슷하면 가까이, 다르면 멀리. 이것이 임베딩의 핵심입니다.”

시뮬레이터 운영 가이드

섹션 제목: “시뮬레이터 운영 가이드”

TokenizerPlayground (토크나이저 실습장)

섹션 제목: “TokenizerPlayground (토크나이저 실습장)”
  • 소요 시간: 약 10-12분
  • 주요 기능: 문장 입력 → 토큰 분리 시각화, 토큰 수 표시
  • 교사 팁: “한국어 vs 영어” 비교를 반드시 포함하세요. 학생들의 서프라이즈 반응이 가장 큰 순간입니다.
  • 추천 입력 예시: “안녕하세요”, “Hello”, ”😀”, “인공지능”, “Artificial Intelligence”, “나는 오늘 점심을 먹었다”

VectorArithmetic (벡터 연산기)

섹션 제목: “VectorArithmetic (벡터 연산기)”
  • 소요 시간: 약 5분 (설명과 함께)
  • 주요 기능: “왕 - 남자 + 여자 = ?” 같은 벡터 연산을 시각적으로 보여줌
  • 교사 팁: 학생에게 먼저 “결과가 뭘까?” 예측하게 한 뒤 결과를 공개하면 효과적입니다.

EmbeddingGalaxy (임베딩 갤럭시)

섹션 제목: “EmbeddingGalaxy (임베딩 갤럭시)”
  • 소요 시간: 약 15-18분
  • 주요 기능: 3D 공간에 단어를 별로 배치, 의미 거리에 따른 위치 관계 시각화
  • 교사 팁: 처음 3분은 교사가 시연(“고양이”, “강아지” 등록), 이후 학생 자유 탐험. 멀티플레이어 기능이 있으므로 같은 반 학생들이 동시에 등록하면 재미있습니다.
  • 주의사항: 부적절한 단어 입력에 대비하세요. 문제 발생 시 “이 시뮬레이터는 학술적 목적”임을 안내합니다.

학생 예상 질문 & 답변

섹션 제목: “학생 예상 질문 & 답변”

Q1. 토큰이 왜 단어 단위로 안 나뉘나요?

“토크나이저는 BPE(Byte Pair Encoding)라는 방법으로 자주 나오는 조합을 합칩니다. 영어 ‘the’는 워낙 자주 나오니까 통째로 하나의 토큰이지만, 한국어 ‘안녕하세요’의 글자 조합은 상대적으로 드물어서 더 잘게 나뉘는 거예요.”

Q2. 임베딩 벡터의 각 숫자는 무슨 뜻인가요?

“사람이 ‘왕족 차원’, ‘성별 차원’ 같은 것을 정해준 게 아닙니다. 기계가 데이터에서 패턴을 찾아 스스로 만든 거예요. 각 차원이 구체적으로 무엇을 의미하는지 사람이 정확히 해석하기 어려운 경우가 많습니다.”

Q3. ‘왕 - 남자 + 여자 = 여왕’이 항상 맞나요?

“항상 완벽하진 않아요. 하지만 많은 경우에 놀라울 정도로 잘 맞습니다. ‘파리 - 프랑스 + 일본 ≈ 도쿄’ 같은 관계도 잡아낼 수 있어요. 핵심은 100% 정확한가가 아니라, 단어의 관계가 벡터의 방향으로 포착된다는 것 자체가 혁명적이었다는 거예요.”

Q4. 한국어가 토큰이 더 많으면 AI가 한국어를 더 못하는 건가요?

“직접적으로 ‘못하는 것’은 아니지만, 같은 의미를 처리하는 데 더 많은 토큰이 필요하므로 비용이 더 들고 처리가 느려질 수 있어요. 최근에는 한국어에 특화된 토크나이저도 개발되고 있습니다.”

Q5. 임베딩은 어떻게 학습되나요?

“2~6차시에서 배운 것과 똑같아요! 거대한 텍스트로 ‘주변 단어를 예측하는’ 신경망을 만들고, 손실함수로 틀린 정도를 재고, 역전파로 가중치를 업데이트합니다. 그 학습된 가중치가 곧 임베딩 벡터입니다.”

Q6. 같은 단어 ‘사과’가 과일과 사과하다 두 가지 뜻이 있는데, 임베딩에서 어떻게 구별하나요?

“Word2Vec에서는 구별이 어렵습니다. 하지만 다음 시간에 배울 ‘어텐션’이라는 기술이 바로 이 문제를 해결합니다. 문맥을 보고 같은 단어의 의미를 다르게 파악하는 거예요.”

Q7. 임베딩 벡터는 실제로 몇 차원인가요?

“Word2Vec은 보통 100~300차원, GPT-4 같은 최신 모델은 수천 차원을 사용합니다. 교과서에서는 이해를 돕기 위해 3차원으로 단순화한 거예요.”
